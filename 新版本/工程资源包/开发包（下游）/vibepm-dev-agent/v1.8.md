# Vibepm Dev Agent v1.8 / 2026-11-06

v1.8 补齐前台工程：新增可直接拿来开发的 WEB 示例工程，并整理 Admin 目录与部分组件表现；开发时按后台 / 前台分别走规范。主要变化如下：

## 升级概要

- **新增 WEB 工程：** 包内提供 `web/`（Vue3 + Vite + TypeScript + Arco），面向官网、落地页与产品站前台；含营销壳、侧栏产品壳、登录壳，对照母版 `frame/web`，不要用后台 Pro 壳。
- **前后台分流：** 同为 Arco 时，后台规范为 arco-design-vue，前台为 vibe-design-web；`feature-dev` 按子项目根目录区分，任务清单与换肤门禁也分开。
- **WEB 工程约定：** 统一请求封装与登录态、Classic 图标；样式按 common / layouts / pages 分层（对齐母版与后台工程习惯）；依赖版本与后台对齐，便于两端一起维护。
- **Admin 与母版：** 样式 / 字体目录收拢；图标升级到 FA Pro 7.3.0；橱窗里分段选择器、Tabs、Steps 等与母版对齐。
- **文档：** `AGENTS.md` 升至 v1.8；接入说明与部署清单已挂上 `web/`。
- **母版预览：** 使用新版 Gallery；WEB 端可预览页面壳；本包不包含 APP 母版（菜单已隐藏）。
- **一并收录：** 此前补充的 Ant Design Pro 示例工程与对应知识库（不对照 Admin 母版）。

## 升级指引

- **备份** 现有 Agent 配置，以及已有的 `admin/`、`web/` 工程
- **复制** 新版 `.agents/`、`AGENTS.md`、`CHANGELOG.md`、`templates/`、`frame/` 到工作区根目录
- **覆盖** `feature-dev`、规范加载相关定义，以及 Admin 的 Arco 知识库；并新增 WEB 知识库目录
- **启用 WEB** 复制包内 `web/`，按其中 `README-DEV.md` 开发；新页面对照母版用 Vue 重写，不要粘贴母版 HTML，也不要改 `frame/`
- **合并 Admin** 若项目里已有后台工程：合并新的样式分层与 FA 7.3.0 资源；知识库里的母版路径以 `frame/admin/assets/common/` 为准
- **验证** 后台功能开发时规范摘要应为 arco-design-vue，前台应为 vibe-design-web；两端分别构建通过。若只有 PRD，须先转成 SRS 再开发

详细变更见 `CHANGELOG.md` · v1.8。
