tabs

标签页

同页内容分区切换，适合详情、配置与日志等多组信息。

组件类型：default / capsule / line / card / vertical

圆角标签页tabs-default
需要权限 提示词
展示内容概览与业务信息。 展示相关参数配置项。 展示操作记录与时间线。
胶囊标签页tabs-capsule
需要权限 提示词
展示总览指标与状态。 展示趋势与对比分析。 展示偏好与默认配置。 展示账单与支付记录。
线条标签页tabs-line
需要权限 提示词
展示项目概览与关键指标。 展示成员列表与角色。 展示近期动态与评论。
卡片标签页tabs-card
需要权限 提示词
卡片标签下的概览面板。 卡片标签下的账单面板。 卡片标签下的安全面板。
纵向标签页tabs-vertical
需要权限 提示词
展示个人资料表单。 展示通知偏好开关。 展示隐私与可见性设置。
