surface-fx

表面装饰

宿主修饰：悬停光晕 / 悬停扫光 / 边框流光 / 悬停抬起，可挂在卡片或区块上。

组件类型：spotlight / shine / border-flow / lift

悬停光晕surface-fx-spotlight
需要权限 提示词

悬停光晕

悬停时主色光斑跟随鼠标。
悬停扫光surface-fx-shine
需要权限 提示词

悬停扫光

悬停时斜向高光扫过表面。
流光边框surface-fx-border-flow
需要权限 提示词

流光边框

悬停时主色高光沿边框旋转。
悬停抬起surface-fx-lift
需要权限 提示词

悬停抬起

悬停上移并加强阴影，不跟鼠标。
