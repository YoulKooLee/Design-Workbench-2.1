# 工作流模式

> 技能含多步骤或分支逻辑时阅读。

## 顺序工作流

复杂任务拆成清晰顺序步骤；宜在 SKILL.md 靠前给出流程概览：

```markdown
填写 PDF 表单包含以下步骤：

1. 分析表单（运行 analyze_form.py）
2. 创建字段映射（编辑 fields.json）
3. 校验映射（运行 validate_fields.py）
4. 填写表单（运行 fill_form.py）
5. 验证输出（运行 verify_output.py）
```

## 条件工作流

有分支时，引导智能体经过决策点：

```markdown
1. 判断修改类型：
   **创建新内容？** → 遵循下方「创建工作流」
   **编辑已有内容？** → 遵循下方「编辑工作流」

2. 创建工作流：[步骤]
3. 编辑工作流：[步骤]
```
