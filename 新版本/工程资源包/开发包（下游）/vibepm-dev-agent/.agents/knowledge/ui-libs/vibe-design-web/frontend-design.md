# Vibe Design WEB · 前端气质边界

在已定 Style（`--wa-*` / `style.md`）与组件规范之内，强化层次、编排与细节；**不**另起一套美学推翻令牌或母版基线。

## 优先级（铁律）

`style.md` > `layouts.md` > `components.md` > **本文** > `pages.md`。

- 已选定 Style / 母版预览时：字体与主色以 token 为准；动效时长与缓动跟 Style Motion（若有）；本文只做层次与细节。
- 与企业官网 / 落地页 / 营销页结构规范并用时：信息架构、容器宽度、CTA 层级、响应式以 `components.md` / `pages.md` 为准；本文不替代转化逻辑。

## 允许

- 在 `--wa-*` 边界内加强对比、留白节奏、区块节奏与克制动效。
- 用意象 / 场景图作视觉锚点（非纯装饰渐变顶替产品语境）。
- 同页内统一圆角、描边、阴影策略，避免多套皮。

## 禁止

- 为「大胆」换掉已定主色、字体栈或 `wa-*` 关键 class。
- 引入泛滥 AI 审美默认（紫渐变白底、与品牌无关的展示字体栈等）覆盖 Style。
- 用 Admin `pro-*` 密度 / 皮肤冒充 WEB 气质。
- 首屏堆砌统计条、多卡片、次要营销块打断主转化（除非 page-type 明确是工作台看板）。

## 与官网 prompt

粘贴 `prompt.md` 时：§4 视觉规格服从 Style；§5 / §7 结构服从母版与 `components.md`；本文不授权跳过 slug 复用。
