# Vibepm Demo Agent v1.5 / 2026-11-06

v1.5 让三端原型更好创建、更好维护：创建前问清关键选项并写入配置，统一交付目录，并理顺 APP 设备壳与主题样式的分工。主要变化如下：

## 升级概要

- **创建流程：** WEB / Admin / APP 创建前一次确认关键选项（风格、站型或设备壳、导航形态等）并写入配置；缺配置时增页须先补齐或询问，避免写错交付根或弄丢风格来源。
- **可拷贝模板：** 提供 WEB / APP 整套页面模板（落地页、产品站、登录，以及 iOS / 微信壳等）；母版更新后可用同步脚本刷新模板。
- **统一目录：** 三端共用同一套交付树（页内样式与脚本、全站公共资源、第三方进 vendor）；Admin 母版也按此收拢。更细的操作说明见 `docs/` 下三端流程文档。
- **APP 样式分工：** 设备外框放在壳结构样式里（换肤不要改）；颜色与字体放在主题样式里（可按所选风格整文件替换）。二者按固定顺序引入。
- **APP 默认主题：** 创建时选「默认」即使用亮色科技蓝；母版主题样式已预先烘焙好。
- **其它：** 图标库升级到 Font Awesome Pro 7.3.0；WEB 母版与官网设计资源对齐；Admin 换肤规则见技能内 Admin 风格说明。

## 升级指引

- **备份** 已有交付目录（`web/`、`admin/`、`app/`）与自定义过的母版
- **覆盖** 原型技能目录（含说明、页面模板与同步脚本）
- **同步** 包根母版目录（重点：APP 壳结构 / 主题样式与各壳页面；Admin 公共资源路径）
- **更新** 根目录 `AGENTS.md`、`CHANGELOG.md` 与本文件
- **保留** 业务产出（需求文档、已交付页面）与风格预设；不要用旧包盖掉已烘焙的主题
- **验证** 落地页、管理后台、APP 壳均走统一原型技能；APP「默认」为亮色科技蓝，换肤后设备外框不变；多个交付根或缺少配置时须先确认或补字段

详细变更见 `CHANGELOG.md` · v1.5。
