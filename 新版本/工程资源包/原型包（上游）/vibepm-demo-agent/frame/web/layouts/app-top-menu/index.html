顶栏全局菜单

将业务视图接入主内容区

通栏顶栏在 LOGO 左侧提供菜单图标，点击展开产品与服务列表。无固定侧栏，主列全宽。顶栏与账号区随路由切换保持不变；主内容区顶部放面包屑，其下接入当前业务视图。

  1. 1

    对齐信息结构

    分组只做分区。父级展开/收起，子级才进页面。把当前选中项映射到本槽页头与正文。

  2. 2

    适合放的内容

    功能说明、上手步骤、权限提示、空状态与下一步。需要数据时再换成表格或详情。

  3. 3

    窄屏怎么用

    顶栏保留菜单图标与品牌；点菜单展开全局面板（不满屏，遮罩不盖顶栏）。窄屏同样用该入口。

  4. 4

    落地时删掉说明

    复制骨架后用产品页替换本区。顶栏布局图标只切页面框架，与业务导航无关。
