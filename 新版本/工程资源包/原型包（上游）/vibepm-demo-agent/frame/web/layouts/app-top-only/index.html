无侧栏通栏

将业务视图接入主内容区

通栏顶栏含品牌与水平主导航，无侧栏，主列全宽。顶栏与账号区随路由切换保持不变。主内容区顶部放面包屑，其下只放当前选中项对应的业务视图，例如列表、详情、表单或空状态。

  1. 1

    对齐信息结构

    分组只做分区。父级展开/收起，子级才进页面。把当前选中项映射到本槽页头与正文。

  2. 2

    适合放的内容

    功能说明、上手步骤、权限提示、空状态与下一步。需要数据时再换成表格或详情。

  3. 3

    窄屏怎么用

    顶栏出产品名与汉堡菜单，水平导航收进顶链抽屉。点父级展开子项，点子项再跳转。面包屑过长会单行截断。

  4. 4

    落地时删掉说明

    复制骨架后用产品页替换本区。顶栏布局图标只切页面框架，与业务导航无关。
