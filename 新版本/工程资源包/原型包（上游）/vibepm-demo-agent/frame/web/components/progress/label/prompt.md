# 带标签进度条

> 状态：preview · slug：`progress-label` · 类型：component · 母版：web · surface：general · category：`feedback`

## 1. 角色与目标

实现「带标签进度条」（`progress-label`）。标题与百分比在条外展示，适合上传与配额场景。

成功标准：业务页出现与 §5 一致的真控件（非说明文案冒充）。

## 2. 实现路径（只走一条）

- **A**（有母版）：**整段粘贴 §5** 到业务页；换文案只改片段内汉字。本条只含一种形态；其它态复制兄弟 slug 提示词。禁止拼装多态橱窗。
- **B**（无母版 / 其它栈）：按 §5 还原本形态。视觉跟宿主库。禁止未探测到 Arco 时强行 import。
- **样式落地**：若有同目录或家族私有样式，将规则**并入**宿主页/模块 CSS；**禁止**在交付里保留独立 `component.css` 或写死 `<link …/component.css>`。

## 3. 约束

- **本提示词只含这一种形态**
- 交互：真 a-progress；`:show-text="false"`；外层标签用 `.wa-progress-label`
- 若有私有样式：规则真源在同目录或家族 CSS；§5 **只贴 HTML**；落地合并进宿主样式，勿在 §5 写独立 link

## 4. 视觉规格

- 布局 / 层级 / 强调：上行左标题右百分比；下行满宽进度条
- 动效：仅本控件轻交互（hover/focus）；Shine / Glow 等可复用装饰 → `animations/`，不写进本控件
- 颜色：只用 `--wa-*` / Arco token（若适用）

## 5. 直接粘贴

```html
<div class="wa-progress-label">
  <div class="wa-progress-label__meta">
    <span>上传进度</span>
    <span class="wa-progress-label__value">75%</span>
  </div>
  <a-progress class="wa-progress-demo" :percent="0.75" :show-text="false" :stroke-width="6"></a-progress>
</div>
```

> 换文案：只改汉字与百分比数字（与 `:percent` 保持一致）。`.wa-progress-label` / `__meta` / `__value` / `.wa-progress-demo` 并入宿主 CSS；勿单独 link。
