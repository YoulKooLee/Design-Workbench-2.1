## 这个包解决什么

补丁是写进项目里的 `node_modules/@axhub/make/dist/admin` 的，**不是**项目源码。
所以下面三种情况都会让补丁消失、界面回到原样：

| 情况 | 结果 |
|---|---|
| `npm install` / `pnpm install` 重装依赖 | `@axhub/make` 被重新解包，admin 覆盖，补丁没了 |
| 升级 `@axhub/make` 版本 | 同上 |
| 手动执行了应用器的 `--revert` | 标签被摘掉、assets 里的文件被删 |

桌面这份是**唯一独立副本**，工作台目录被清、被重装都还能拿回来。

---

## 怎么恢复（任选一种）

**方式一：双击 `restore.cmd`** —— 装回默认项目「上下文装配测试」，弹出窗口显示结果。

**方式二：命令行**

```bash
node restore.mjs                 # 装到「上下文装配测试」
node restore.mjs --all           # 装到探测到的所有项目
node restore.mjs --list          # 先看哪些项目装了 @axhub/make、各自有没有补丁
node restore.mjs --project "D:\...\01-项目\某项目"
```

装完刷新浏览器（`Ctrl + F5`，避开缓存）即可看到新版界面。

**方式三：双击 `watch.cmd`（防还原）** —— 每 3 秒检查一次，一旦发现补丁被冲掉就自动装回，
窗口关掉才停止。适合「马上要重装依赖」或「不想再管」的场景。

**回退**：双击 `revert.cmd`，或 `node restore.mjs --revert`。回退后与原版完全一致。

## 几个前提要知道

1. **admin 是全局单例**，53817 端口只有一个实例，谁启动就吃谁的 admin。
   补丁要生效，必须从这个项目目录启动：
   ```bash
   cd "D:\产品设计工作台\01-项目\上下文装配测试"
   NODE_OPTIONS="" node node_modules/@axhub/make/bin/cli.mjs --no-open --port 53817
   ```
   `NODE_OPTIONS=""` 不能省 —— 继承到 safe-delete 钩子会让服务的临时文件删不掉，
   从而误报「本机数据目录不可写」并弹窗压暗整页。

2. **工作台源码里也有同一份**，路径 `D:\产品设计工作台\90-运行脚本\studio-ui\`，
   `restore.mjs` 也已同步过去，在那里可以直接 `node restore.mjs` 跑。
   改了补丁请两边同步，否则哪天分不清哪份是最新。

3. **设备预设（桌面/平板/手机）没做**，是实测后主动撤掉的：
   画布 iframe 内部是「设计稿 + 设计说明」两栏自适应，改宽度会把右栏压成竖排再裁掉半截。
   等原型侧支持响应式再补。

4. **右栏三 tab（批注 / 评审 / 设计说明）没做**：那块「设计说明」是原型
   `src/common/PrototypeLayout.tsx` 画在 iframe 里的，跨源改不动，要动得改项目源码。
