## 四、模块快照（跨端不失忆的解药）

> 每模块 ≤300 字。检测到压缩就**立即补**；模块闭环时也立即写。
> 模板见 `.agents/rules/compaction-recovery.md`。

```markdown
## 模块快照：<模块名>（端：web | mobile | both）
- 状态：已完成 / 进行中（完成度 %）
- 职责：一句话
- 对外接口：契约（输入实体 → 处理 → 输出实体）
- 依赖模块：上游 X / 下游 Y
- 数据实体：与 HLD 数据模型对齐
- 数据流：闭合 / 待补 ← 待补的模块不得进下一个
- 关键决策：≤3 条
- 跨端差异：web 已实现部分，mobile 需注意什么
- 未完成 TODO：≤3 条
```
