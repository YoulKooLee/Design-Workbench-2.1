> ⚠️ **本文件是上下文衰减的兜底**：`AGENTS.md` 只在会话首轮注入一次，压缩**不会**把它带回来。
> **读到本行 → 顺手确认一次 `AGENTS.md` 是否还在上下文里**；不在就 Read 一次它和 `.agents/skills/INDEX.md`。（触发条件是「读到本行」这个动作，不是「想起它不在」——后者不可能发生。）

> **会话别开太长**：按模块 / 阶段新开会话，是让 `AGENTS.md` 重新注入的唯一办法。

## 四、模块快照（常驻基线第 6 项 · 跨端不失忆的解药）

> 模板与字段定义见 `.agents/rules/compaction-recovery.md`「模块完成快照」，每模块 ≤300 字，只写摘要与路径。
> **时机（2026-10-30 定调）**：不等 hook、不等验收——检测到压缩就**立即补**当前模块快照；模块闭环通过时也立即写，不攒到会话末尾。
> 「怎么知道压缩过了」：① 想不起上一轮读过什么文件；② 早前细节只剩「做了什么」没有「看到了什么」；③ 文件内容与记忆不符。任一出现即当作已压缩。
> 没验完也照写，状态写「进行中（完成度 x%）」+ 下一步。

```markdown
## 模块快照：<模块名>（端：web | mobile | both）
- 状态：已完成 / 进行中（完成度 %）
- 职责：一句话
- 对外接口：契约（输入实体 → 处理 → 输出实体），不写实现
- 依赖模块：上游 X（取什么数据）、下游 Y（给什么数据）
- 数据实体：本模块读写的实体名（与 HLD 第三章数据模型对齐）
- 数据流：闭合 / 待补（缺什么）      ← 待补的模块不得进下一个模块
- 关键决策：≤3 条，只写结论 + 一句理由
- 跨端差异：web 已实现的部分，mobile 需注意什么（组件/交互/字段差异）
- 未完成 TODO：≤3 条
```

> **跨端失忆的解法**：移动端启动某模块时，装配 = 常驻基线（含 web 端该模块快照）+ 移动端滑窗 → 读到接口契约与跨端差异，**不需重读 web 端实现**。
