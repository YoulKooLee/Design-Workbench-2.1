## 这份文件夹是什么
本文件夹用于存放项目基线文档，包括但不限于三件套（`docs/01-需求与规划/*SRS*.md`、`docs/02-架构与设计/*概要设计*.md` / `*详细设计*.md`），是智能体和人都可查阅的事实来源，需要时按需加载，而非常驻注入。
读到本行 → 顺手确认一次 `AGENTS.md`、`project-memory.md` 是否还在上下文里，不在就重读一次。
