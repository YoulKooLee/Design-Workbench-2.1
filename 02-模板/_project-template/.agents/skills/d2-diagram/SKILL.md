# d2-diagram

## 何时用 / 何时不用

| 情况 | 用哪个 |
|---|---|
| 图是**独立交付物**：架构总览、数据流、时序、能力地图；要求版式好看、以后要随文档重画 | **本技能** |
| 图要**嵌进 PRD / SRS 正文**，还要让业务方在 draw.io 里改 | `drawio-generator` |
| 只是文档里一张小示意、改一次就完 | `diagram-generator` |

判据：**这张图以后还会不会重画？会 → 本技能；不会 → drawio。**

## 步骤

1. **定图型**：架构 / 流程 / 时序 / 关系——决定布局（见基线第三节）。
2. **读源**：从 `docs/` 的 PRD / SRS / HLD 或代码里抽节点与关系；**不要凭印象画**。读哪份要能说出路径。
3. **写 `.d2`**：套 `diagram-baseline.md` 的 classes 段；节点文字 ≤12 汉字。
4. **渲染**：
   ```powershell
   $d2 = "<工作台根>\08-办公\画图\d2.cmd"
   & $d2 --layout=tala --pad=24 <名字>.d2 <名字>.svg
   & $d2 --layout=tala --pad=24 <名字>.d2 <名字>.png
   ```
5. **看结果**：打开 PNG 自查（有没有压字、交叉线、孤立节点、>3 种颜色）。
6. **落盘**：见下。

## 落点

| 件 | 位置 |
|---|---|
| 源 | `<项目>/docs/03-图示/<名字>.d2` |
| 渲染 | 同目录 `.svg`（进文档）、`.png`（进汇报） |
| Make 预览副本 | `<项目>/src/resources/` |

样式规范：`<工作台根>/08-办公/画图/diagram-baseline.md`（单一真源，别在单张图里另设风格）。

## 坑

1. **源文件必须 UTF-8 无 BOM**。PowerShell 5.1 的 `Set-Content -Encoding utf8` 会写 BOM，导致首行（如 `direction: right`）解析错、变成一个节点。用：
   ```powershell
   [System.IO.File]::WriteAllText($p, $src, (New-Object System.Text.UTF8Encoding($false)))
   ```
2. **跨容器引用要写全路径**。容器内定义的节点，外部引用必须写 `界面.ScreenShell.三维`；只写 `三维` 会在顶层**另建一个同名节点**，图上出现重复方框。
3. **容器默认带蓝色底**。要中性外观必须显式 `class: frame`（基线里已备好），否则外框是浅蓝，与节点配色打架。
4. **连线从容器出发更居中**。从深层子节点拉线会把整个布局拽偏；用 `界面 -> 适配`，不要 `界面.ScreenShell.三维 -> 适配`。
5. **脚本里调 `.cmd` 会 EINVAL**。node 的 `execFileSync` 不能直接 spawn `.cmd`（需 shell）。脚本中直指 `d2-v0.9.0/bin/d2.exe`；只在 PowerShell 手敲时用 `d2.cmd`。
6. **路径含空格要引号**；工作台路径本身含中文与空格，用变量传，别拼裸字符串。
7. **中文靠本机字体**：本机渲 PNG 正常；SVG 拿到别人机器可能缺字形，对外交付给 PNG。
8. **布局别硬调**：先换 `--layout`（elk / dagre / tala），实在不行再改层级结构，不要用 `near` 硬拉位置。

## 自检

- [ ] 节点数 ≤ 15；超了就拆成两张
- [ ] 节点文字没有超 12 汉字的
- [ ] 颜色 ≤ 3 种
- [ ] 没有孤立节点、没有穿过节点的连线
- [ ] `.d2` 与 `.svg` / `.png` 都已落盘，且 `.d2` 里能看出图对应哪份文档
