# draw.io 图表模板库

> **人类浏览用索引。** AI Agent 执行时以 [`SKILL.md`](../SKILL.md) 中的类型对照表与模板选型指南为准；本文件便于在 IDE 中快速查阅各模板示例内容。

各 `.xml` 文件为完整业务示例，可直接在 draw.io / diagrams.net 中打开参考。

## 模板索引

| 文件 | 触发类型 | 示例内容概要 |
| --- | --- | --- |
| `flowchart.xml` | 流程图 / 活动图 | 用户注册全流程：格式校验、短信验证码、账号查重、多分支错误回路与成功路径 |
| `architecture.xml` | 技术架构图 | 企业 SaaS 五层架构：接入层、网关层、11 个微服务、6 种存储、基础设施 + 8 个第三方系统 |
| `system-arch.xml` | 系统功能架构图 | 电商订单平台：左侧层标签（终端/核心业务/基础数据/外部集成）+ 模块矩阵 + 底部图例 |
| `sequence.xml` | 时序图 | 下单支付：6 参与者、3 阶段分组、16 条同步/异步消息（库存预占、支付回调） |
| `swimlane.xml` | 纵向泳道图 | 费用报销：5 角色纵向泳道、OCR 校验、主管驳回循环、财务/HR 分级审批 |
| `cross-functional.xml` | 横向泳道图 | 员工请假：4 职能横向泳道（员工→直属主管→HR→财务）、驳回修改回路 |
| `matrix-swimlane.xml` | 矩阵泳道图 | 电商订单履约：6 角色 × 5 阶段二维矩阵（下单→备货→配送→售后→异常） |
| `bpmn-flow.xml` | BPMN 流程图 | 采购审批：排他网关（金额分支）+ 并行网关（财务/法务会签）+ 驳回回路 |
| `er-diagram.xml` | ER 图 | 电商订单域 7 张表：users、roles、user_roles、orders、order_items、products、payments |
| `uml-class.xml` | 类图 | 订单域 7 个类：继承、组合、关联、依赖、接口实现（PaymentGateway） |
| `uml-usecase.xml` | 用例图 | CRM 系统：3 Actor、3 子系统边界、12 用例、include/extend 关系 |
| `uml-state.xml` | 状态图 | 订单 9 态状态机：草稿→待支付→…→已完成，含取消/退款分支与说明注释 |
| `orgchart.xml` | 组织结构图 | 四级架构：董事会→CEO→5 VP→11 部门→岗位编制，含人数标注 |
| `mindmap.xml` | 思维导图（左右平衡） | SaaS 产品规划：中心主题 + 5 分支左右展开，彩色曲线 |
| `mindmap-vertical.xml` | 思维导图（自上而下） | 健身 App：主题置顶，4 个一级模块横向排开，二/三级向下延伸，正交连线 |
| `mindmap-radial.xml` | 思维导图（放射状） | 智能客服立项：中心向 6 方向辐射，高饱和分支色，适合 brainstorm |
| `mindmap-minimal.xml` | 思维导图（简约线框） | Q2 OKR：灰阶直角无阴影，Objective + KR 结构，适合正式汇报 |

## 架构类模板区分

| 模板 | 适用场景 |
| --- | --- |
| `architecture.xml` | **技术**分层：微服务、网关、中间件、数据库、第三方 API |
| `system-arch.xml` | **功能**分层：左侧业务层标签 + 各层功能模块分组 + 图例说明 |

## 泳道 / 流程类模板区分

| 模板 | 适用场景 |
| --- | --- |
| `flowchart.xml` | 单角色线性流程，无泳道 |
| `swimlane.xml` | 多角色**纵向**泳道（角色为列） |
| `cross-functional.xml` | 多职能**横向**泳道（职能/阶段为行） |
| `matrix-swimlane.xml` | 角色 × 阶段**二维矩阵** |
| `bpmn-flow.xml` | 标准 BPMN：排他网关 ◇、并行网关 + |

## 层级 / 发散类模板区分

| 模板 | 适用场景 |
| --- | --- |
| `orgchart.xml` | **汇报关系**层级：上下级、部门编制 |
| `mindmap.xml` | **左右平衡**发散：默认彩色 B 端风 |
| `mindmap-vertical.xml` | **自上而下**层级：功能/WBS 拆解 |
| `mindmap-radial.xml` | **四周辐射**发散：brainstorm、立项 |
| `mindmap-minimal.xml` | **简约线框**：OKR、汇报、打印 |
