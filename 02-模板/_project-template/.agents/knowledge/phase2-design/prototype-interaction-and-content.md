# 原型交互与内容规范

> 来源：open-design prototype 上下文工程转译（Apache-2.0，已剥离 OD 专属协议），2026-10-23 自 `08-文档/更新材料2026.10.22` 整合。
> 与 `prototype-design-baseline.md` 配套：那份管"长什么样"（视觉基线），本份管"怎么动、怎么反馈、内容怎么真"。

## 一、完整交互状态（9 态）

关键动作有清晰可点击的可得性与结果反馈，声明的流程需要处处理 **default、hover、focus、selected、loading、empty、success、failure、disabled** 各态。

- 模态、菜单、抽屉与页面转场有明确入场、出场与返回路径。
- 模态表单优先原生 `<dialog>` + `showModal()`。对话框**可见后**再放初始焦点，而不是入场动画隐藏它时。每条关闭路径把焦点还给活跃控件：重建列表后按稳定条目 ID 找新触发器；条目不再可见时聚焦主行动而非游离节点。
- 重建或移动条目的内联动作也把焦点恢复到新渲染的等价控件；过滤器移除时给可见回退。
- 按钮驱动的视图变化与成功跳转由本地状态驱动并直接调用视图渲染器，不依赖 `location.hash` 或原生文档导航在沙箱中更新视图；被拒的 URL 更新不得阻塞导航、已提交结果或保留用户过滤器的返回路径。
- 每次本地变更提交到渲染界面的同一状态；显示列表、过滤结果、合计、可用性与图表标签前从该已提交状态派生。仅保存复制的列表不得让可见列表或其摘要过期。刷新每个已挂载的已变更值视图（含抽屉或编辑器后面的复核页）；使基于旧值的确认失效；最终确认使用用户在复核中看到的同一当前值。
- 状态措辞从与显示合计相同的值派生。区分无记录、零、正净额与负净额——零不得称为正余额或增长。空周期显示诚实的空状态，无过期图表段或编造百分比。
- 热搜索建议与键入搜索用同一匹配规则；可见建议必须能找到其预期的现有内容（含建议缩写较长标题时）；清空搜索恢复适用的列表与过滤器。
- 原型动作必须在工作台预览沙箱内可工作，无原生表单提交或导航。本地增/存用 `type="button"` 点击处理器与 Enter 键处理器调用同一本地更新，不单靠表单 submit 事件。
- 使用语义控件、可见键盘焦点、可访问名、有用 alt、非颜色状态线索与 reduced-motion 行为。
- 动效只存在于解释状态变化、层级或动作结果——绝不是无目的装饰。

## 二、可用表单与反馈

- 每个输入有持续可见标签——绝不让 placeholder 代替；必填字段清晰标记。
- 错误消息出现在违规字段旁并解释原因与补救——绝不只是"输入无效"；多错误时顶部给汇总并链接到各字段。
- blur 时验证而非每击键；提交期间显示加载态，结束时给成功或失败反馈。
- 复杂选项渐进披露，不首屏倾倒所有字段；高频动作突出、危险动作视觉区分、破坏性动作前要确认步骤。
- 空状态解释为何为空与下一步——绝不是空白屏。
- 保持未触碰且成功重置的表单无错误消息；只有用户验证了无效值后才显示字段错误。结果与其空状态绝不同时出现。

## 三、可预测导航

- 底部导航最多 5 项，图标配文字标签；当前位置有明显选中态。
- 同级绝不混用底部导航、侧栏与顶部标签；大屏优先侧栏、小屏底部或顶部导航。
- 返回行为可预测：回到上一级恢复滚动位置与已输入内容——绝不静默跳回首页。
- 模态与抽屉有明确关闭方式；绝不用模态承载主流程导航。
- 导航跨页同位，不随页面类型移动。

## 四、真实使用环境

- 移动端：优先触控可达、单手使用、内容滚动与系统安全区；触控目标不小于 44×44pt，相邻目标间距 ≥8px。
- Web 应用：优先多变窗口宽度、内容重排与键鼠操作；可点击元素给 pointer 光标与 hover 反馈。
- 落地页：建立清晰叙事顺序，核心价值与主 CTA 尽早呈现。
- 响应式按 375 / 768 / 1024 / 1440 断点组织，重组内容而非缩放整页；每个断点适配而不隐藏关键动作或破坏阅读顺序；移动端永不横向滚动、不禁缩放。
- 固定页头、底栏与浮动控件为覆盖内容预留匹配 padding。
- 手机原型用设备外壳呈现（见 `03-组件库/03-页面组件/设备外壳/`）：外壳是**呈现，不是设计系统**——它不为应用设定字体、调色板、间距、组件或导航；绝不把 Android 应用放进 iPhone 外壳或反之。

## 五、感知性能

- 声明图像宽/高或比例，为异步内容预留空间，加载后不位移。
- 超 300ms 的等待给骨架屏或进度指示——绝不长空白或裸 spinner。
- 超 50 项的列表分页、虚拟化或分批加载。
- 只动 transform 与 opacity；绝不触碰 width、height、top 或 left。

## 六、真实、一致的内容

- 优先用户提供的文案、图片、品牌资产与真实数据。
- 无真实数据时，用与业务一致的可信示例内容——绝不用无意义占位文本；保持名字、日期、数字与状态一致。
- 图片、图标与插画匹配内容含义并保持统一风格；本地化图片匹配可见主体——不把无关图像改名当作请求的地点或对象；精确图像不可用时用清晰披露的中性占位符而非误导性照片。
- 绝不编造用户未提供或未确认的品牌事实、功能承诺或业务数据。
- 演示内容默认真实指称物（书架显示真书真封面）；虚构替身是例外：仅当用户要求虚构内容或许可禁止真实资产时使用，并在交付说明披露。

## 七、图表与图标的工程实现约束

- SVG 绘制元素保持在一个真实 `<svg viewBox="...">` 根内；JS 构建时用 `document.createElementNS('http://www.w3.org/2000/svg', ...)` 或插入 SVG 标记到现有 SVG 根；绝不向 HTML `div` 注入裸 `path`/`line`/`text`。
- 图表要有可见视口与显式尺寸；绘点、轴与标签保持在视口内——空图表容器不是已渲染图表。
- 功能性 UI 字形（菜单勾选、定位钉、箭头、状态标记、控制图标）统一尺寸契约：图标自己拥有尺寸（`1em` 默认或显式图标尺寸变量），绝不把尺寸散布到父级选择器如 `.menu-item svg`；内容 SVG（图表、示意图、logo、地图、插画）保留自身显式几何，不走 UI 字形尺寸规则。
- 动态 UI 优先把 DOM 结构与数据分离：纯文本用 `textContent`，属性用 DOM 属性或 `setAttribute`；按插入上下文转义数据。简单代码保持简单，不只为遵循指导加抽象。

## 八、DOM 一致性底线（原型常见事故清单）

- `querySelector` 返回一个元素或 null；`querySelectorAll` 返回集合。不迭代单元素查找，不混用选择器辅助的返回类型。
- 初始化错误不得让种子内容与控件保持未绑定。切换 `hidden` 时保留原生隐藏态规则（含 `until-found` 例外）；组件 flex/grid 显示规则不得暴露隐藏对话框、验证消息或空状态。
- 保持无 `open` 的原生 dialog 不可见，即使其组件类用了 flex/grid；打开与关闭必须保留原生 dialog 状态。
- 处理器、标签与验证反馈选择器与实际渲染标记中的 ID 一致；不要混用输入与字段命名方案派生反馈 ID；可选反馈节点必须空安全。
- 对渲染器插入或替换的控件，从稳定祖先委托事件或在插入后绑定；重新打开视图必须保留可用处理器而不累积重复动作。

## 九、质量底线（写源码时一次满足）

- 字体引用可解析；布局无溢出或裁剪风险；对齐结构完整。
- 图片几何成立：本地化图像按实测固有尺寸取比例并整幅渲染；cover 裁切只留给装饰背景。
- 核心流程每步真实实现；按钮、导航与关键控件绑定真实行为，不是装饰。
- 响应式覆盖 375px 与宽屏；无横向滚动；固定栏为覆盖内容预留 padding。
- 正文对比 ≥4.5:1；暗色独立选色；主控件前后景都设，含 hover、focus 与 disabled 态。
- 主交互键盘可达，源码显式定义焦点样式与焦点顺序。
- 锁定内容、用户指定资产与非目标区域保持未触碰——无意外编辑。
