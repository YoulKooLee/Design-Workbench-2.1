# 原型设计基线

> 用**可核验值**替代主观判断。用户显式要求、品牌系统或现有制品定义了不同值时遵循它们，但在交付说明中注明偏离。
> 来源：open-design prototype 上下文工程转译（Apache-2.0，已剥离 OD 专属协议：daemon CLI / od-* 标记 / .od-frames staging / data-od-id / React UMD），2026-10-23 自 `08-文档/更新材料2026.10.22` 整合。

## 一、可核验基线值

| 维度 | 基线值 |
|---|---|
| 对比度 | 正文对背景 ≥ 4.5:1；大字号（≥18px）、图标与关键图形 ≥ 3:1；暗色独立审计，绝不从亮色推断 |
| 字体 | 一致字体阶梯；屏显正文 ≥ 16px；行高 1.5–1.75；桌面行长 65–75 字符、移动 35–60 |
| 间距 | 以 4 或 8 的倍数构建节奏，无任意值 |
| 动效 | 小交互 150–300ms；更大转场 ≤ 400ms；出场为入场的 60–70%；入场 ease-out、出场 ease-in；列表交错 30–50ms |
| 安全区 | 关键信息、行动号召与品牌标在画布中央 70–80%，距边 ≥ 50px |
| 无障碍 | 绝不只靠颜色（配文字/图标/形状）；有意义的 alt；可见焦点态与可访问名；系统字体缩放与 reduced-motion 下不破版 |
| 图标 | 每个交付物统一图标族，描边宽与圆角一致；同级禁混填色与描边；禁 emoji 当功能图标 |

## 二、风格三旋钮（任务配置提供时执行，并记录到设计说明）

- **视觉风格**：设定调色板性格、字体配对与圆角/阴影强度；所选风格**绝不豁免**下方反 AI 光泽规则。无品牌时按场景推断并用一句话说明选择——政府/考试类倾向冷静可信的低饱和蓝绿、细节克制；工具/效率类倾向中性高对比极简；儿童/教育类倾向明亮圆角、插画感。
- **信息密度**：设定间距档位——relaxed 24–96px / standard 16–64px / compact 8–32px；**compact 绝不意味着缩小字号或压扁留白层级**。
- **动效强度**：restrained 只做状态反馈 / standard 加转场与列表入场 / rich 可用滚动驱动与多元素编排。三档都保持在基线时长限制内，且必须支持 reduced-motion。

## 三、原型文案长度预算（作者文案，永不截断/钳制）

| 位置 | 上限 |
|---|---|
| chip 标签 | ≤ 4 汉字 |
| tile（卡片/瓦片）名称 | ≤ 5 汉字，且 ≥ 14px |
| 媒体上标语 | 1–2 行，≤ 12 汉字 |
| 按钮标签 | 单行 |

放不下就缩短文案或改容器；**带省略号的标语不是设计**。

**数据文本**（名称/地址/描述/评论/用户数据）在列表/chip/轨道中可截断（单行省略号），卡片中可钳制（≤3 行）；确认、订单与详情屏全文换行；截断值点按可达（展开/弹层/详情屏），`title` 属性单独不是移动端路径。

**永不截断、钳制或换行**：价格、时间、数量、可用性与状态、主行动标签、错误。数字+单位、价格+「起」、日期+星期用 `nowrap` 钉在一起。

## 四、反 AI 光泽清单（跨所有原型页面默认禁止）

- 以暖米色/奶油/桃/橙棕作页面默认底——从中性或品牌衍生底开始；
- 紫渐变晕染，或渐变铺满每个背景层；
- Inter、Roboto、Arial 或其他库存 UI 字体作**展示字体**（作正文仍可）；
- 左侧彩条圆角卡片作为提示卡模式；
- 每个标题旁放图标，或同一视口为同一动作放多个实心按钮；
- hover 状态把文字变灰或变浅；
- 手绘 SVG 人物或场景作装饰；
- 编造指标（「快 10 倍」「99.9% 可用性」）或无意义填充文案——用诚实、明确标注的占位符代替；
- 无商业理由的渐变、玻璃效果、霓虹光、超大圆角与装饰性卡片堆叠；
- 交付暴露设计者/演示者控件的产品制品——视口选择器、平台切换、演示面板与生成设计元数据都不是应用 UI。

## 五、按类型取图

- **真实指称物**（具名书封面、真实产品、品牌标、真实地点/人物/事件）用**真实图像**：用户资产优先，其次官方/品牌提供资产，再考虑图库照片；**绝不生成真实指称物的替身**（与编造用户数据同类的事实错误）。
- **通用类别/插画类**（示例人物、场景、主视觉）默认也用用户资产或授权图库图。
- **图表、示意图、图标、文字重图**用代码构建（SVG/CSS/HTML），不拍照不生成。
- **绝不** hotlink 外部图片；每张图落地为本地文件或内联 data URI，相对引用。
- 演示与示例内容默认使用真实、知名的指称物及其真实图像；绝不为了规避获取真实资产而「去真实化」内容。
- 图片几何：写样式前先读文件固有宽高；容器按实测比例（aspect-ratio 或自然流）；`object-fit: cover` 只给可刻意裁切的装饰填充，内容图整幅渲染绝不裁切扭曲。

## 六、布局与变长文本

- 一条信息 = 一个块级行（`<span>` 兄弟永不携带两条信息，`<button>` 内也如此）。
- 主内容区按正常流（flex/grid）；固定/粘性 chrome 为覆盖内容预留匹配 padding；绝对定位只留给装饰角标。
- 变长文本写前三选一：自动尺寸块内换行+行钳制 / 省略号单行+一次点击可达 / 详情收到披露后面——绝不允许未声明溢出或裸 `overflow:hidden`。
- 短 CJK 标签用 `white-space: nowrap` + `<wbr>` 在短语边界断行。
- pointer-only 样式放 `@media (hover: hover)`。
- 布局原语参考：`../../../../../03-组件库/03-页面组件/Codebuddy Design/布局/`（Layout / PageHeader / Tabs / Toolbar 等纯结构原语，不设调色板、字体与组件外观）。

## 七、冲突取舍顺序

可访问且可读 > 可用交互 > 信息层级 > 风格表达 > 装饰密度。

当视觉决策来自本基线而非用户资产或品牌指南时，在交付说明中注明；绝不把它当作用户已确认的选择。
