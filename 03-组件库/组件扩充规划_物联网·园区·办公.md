## 二、物联网平台（建议分类名：`物联网`）

**典型页面**：设备列表 · 设备详情 · 实时监控 · 告警中心 · 规则配置 · 设备拓扑 · 点位管理 · OTA 升级

### P0（8 个，没它做不了页面）

| 组件 | 用途 | 关键能力 |
| --- | --- | --- |
| `DeviceStatusTag` | 设备在线状态标 | 在线/离线/故障/未激活/维护，带呼吸点与色阶 |
| `DeviceCard` | 设备卡（宫格用） | 名称 + 型号 + 状态 + 信号 + 最后上报，点击进详情 |
| `DeviceGrid` | 设备状态宫格 | 卡片矩阵 + 状态筛选 + 快捷操作，支持 2/3/4 列切换 |
| `TelemetryChart` | 遥测曲线 | 多轴时序 + 阈值线 + 时间范围切换 + 单位 + 缩放 |
| `MetricGauge` | 指标仪表盘 | 单值 + 量程 + 阈值分区配色（水温/压力/流量） |
| `AlarmList` | 告警列表 | 级别 + 来源设备 + 时间 + 状态，支持确认/批量处理 |
| `AlarmLevelTag` | 告警级别标 | 紧急/重要/次要/提示 四级色阶 |
| `RealTimeValue` | 实时值 | 数值滚动 + 单位 + 质量戳 + 刷新态（配实时推送语义） |

## 七、落地步骤（每个组件）

1. **库侧源码**：`Codebuddy Design/<分类>/<组件名>.tsx`，在 `<分类>/index.ts` 追加 `export *`。
2. **模板落位**：`02-模板/_project-template/src/component-templates/<分类>/<组件名>/`
   - `index.tsx` 重导出、`index.html` 预览壳、`preview.tsx` 带**真实示例 props**
   - ⚠️ make 只扫顶层目录且**判断标准是该目录存在 `index.tsx`**，分类目录本身也要有
3. **五处登记**：`_meta/components.catalog.json` → `custom-components.json` → `分类/index.ts` → `提示词手册.md` → `选型映射.md`；`index.json` / `component-registry.json` 版本号与组件数同步。
4. **门禁自检**：`_meta/sync-registry.mjs --check`（退出码 0）+ 无头浏览器逐页实测无兜底文案。
5. **文档同步**：`gallery.html` 卡数/分区/版本、`README.md` 统计、提示词手册、选型映射。

**硬约束提醒**（沿用现有 6 条契约）：React 18 + Tailwind v4、配色只取 `_kit/theme.css` token、**零第三方依赖**（需依赖的走 catalog `extraDependencies` 方案 B）、源码自包含整目录复制。
