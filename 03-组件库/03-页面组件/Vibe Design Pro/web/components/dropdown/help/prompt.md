# 帮助菜单

> 状态：preview · slug：`dropdown-help` · 类型：component · 母版：web · surface：general · category：`navigation`

## 1. 角色与目标

实现「帮助菜单」（`dropdown-help`）。圆形信息图标触发文档与快捷键入口。

成功标准：业务页出现与 §5 一致的真控件（非说明文案冒充）。

## 2. 实现路径（只走一条）

- **A**（有母版）：**整段粘贴 §5** 到业务页；换文案只改片段内汉字。本条只含一种形态；其它态复制兄弟 slug 提示词。禁止拼装多态橱窗。
- **B**（无母版 / 其它栈）：按 §5 还原本形态。视觉跟宿主库。禁止未探测到 Arco 时强行 import。
- **样式落地**：若有同目录或家族私有样式，将规则**并入**宿主页/模块 CSS；**禁止**在交付里保留独立 `component.css` 或写死 `<link …/component.css>`。

## 3. 约束

- **本提示词只含这一种形态**
- 交互：真 a-dropdown；圆形图标触发
- 若有私有样式：规则真源在同目录或家族 CSS；§5 **只贴 HTML**；落地合并进宿主样式，勿在 §5 写独立 link

## 4. 视觉规格

- 布局 / 层级 / 强调：信息图标触发；文档 / 快捷键 / 支持项
- 动效：仅本控件轻交互（hover/focus）；Shine / Glow 等可复用装饰 → `animations/`，不写进本控件
- 颜色：只用 `--wa-*` / Arco token（若适用）

## 5. 直接粘贴

```html
<a-dropdown>
          <a-button type="secondary" class="wa-dropdown-icon-btn" aria-label="帮助">
            <template #icon><icon-info-circle /></template>
          </a-button>
          <template #content>
            <a-doption>
              <template #icon><icon-book /></template>
              文档中心
            </a-doption>
            <a-doption>
              <template #icon><icon-keyboard /></template>
              快捷键
            </a-doption>
            <div class="wa-dropdown-sep" role="separator"></div>
            <a-doption>
              <template #icon><icon-question-circle /></template>
              联系支持
            </a-doption>
          </template>
        </a-dropdown>
```

> 换文案：只改汉字，勿改 class / type。有私有样式时并入宿主 CSS，勿单独 link `component.css`。
