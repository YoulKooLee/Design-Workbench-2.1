顶栏模块导航

将业务视图接入主内容区

顶栏为一级模块（电商运营 / 项目管理 / 支付中心 / AI 对话）。切换一级后，左侧只显示该模块下的菜单，且默认全部展开。子项进入页面；主列放当前选中项对应的业务视图。

  1. 1

    对齐信息结构

    顶栏一级只做模块切换。左侧是该模块的菜单树，默认展开；子级才进页面。

  2. 2

    适合放的内容

    功能说明、上手步骤、权限提示、空状态与下一步。需要数据时再换成表格或详情。

  3. 3

    窄屏怎么用

    顶栏出汉堡，下拉菜单面板（对齐无侧栏通栏）按一级模块分组展开；点子项再跳转。

  4. 4

    落地时删掉说明

    复制骨架后用产品页替换本区。顶栏布局图标只切页面框架，与业务导航无关。
