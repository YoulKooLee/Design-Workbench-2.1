# 组件选型映射（哪个模块用哪个组件）

> **用途**：绘制原型时，智能体按本表**先选组件、再落页面**，避免每个页面重造一套控件与样式。
> **怎么用**：跟智能体说「按 `03-组件库\03-页面组件\Codebuddy Design\选型映射.md` 做 XX 页原型」，或直接把下面「整页提示词模板」整段复制给它。
> **前置**：组件目录已复制到工程 `src/component-templates/axhub/`（见 README §3）。
> **组件清单与提示词**：见同目录 `提示词手册.md`。

## 1. 页面类型 → 组件组合（对齐 v1.4 admin 母版 50 个 page-type）

| 页面类型（母版 page-type） | 用什么组件组合 |
| --- | --- |
| 查询表格 / CRUD 列表 `list` | `PageHeader`（可选）+ `FilterBar` + `TableCard`(`Toolbar`+`DataTable`+`Pagination`) + `StatusTag` + `ConfirmModal` + `message` |
| 卡片列表 `list-card` | `FilterBarInline` + `Grid(cols=3)` + `Card` + `Tag` + `Pagination` |
| 左树右表 `list-tree-table` | `Grid`/`Row·Col` + `Tree`（左，约 240px）+ `TableCard`（右） |
| 侧栏筛选列表 `list-filter-table` | `Card`（左侧筛选表单，`FormField`+`CheckboxGroup`+`RangePicker`）+ `TableCard`（右） |
| 标签筛选列表 `list-tag-filter` | `FilterBarInline`（`RadioGroup buttonStyle` 或 `Tag closable`）+ `DataTable` |
| 主从分栏 `list-master-detail` | `List`+`ListItem`（左）+ `DetailCard`+`Descriptions`（右） |
| 行内编辑 `list-editable` | `DataTable`（列内放 `Input`/`Select`）+ `FormActions` + `message` |
| 导入向导 `list-import` | `Steps` + `Upload(mode="drag")` + `Alert` + `ResultPage` |
| 基础表单 `form-basic` | `Card` + `FormField`/`FormRow` + `FormActions` + `message` |
| 分组表单 `form` | `SectionCard`（多组） + `FormRow` + `FormActions` |
| 分步表单 `form-step` / `form-step-vertical` | `Steps` + `Card` + `FormRow` + `FormActions` |
| 基础详情 `detail` | `PageHeader` + `DetailCard` + `Descriptions` + `Tag` |
| 高级详情 `detail-advanced` | `PageHeader` + `Tabs`（概览/流程/日志） + `Descriptions` + `Steps` + `List`+`ListItem`（日志流） |
| 成功 / 等待 / 警告 / 失败结果页 `result-*` | `ResultPage status="success\|waiting\|warning\|error"` + `Button` 操作组 |
| 异常页 `exception-403/404/500` | `ResultPage status="403\|404\|500"` +「返回首页」按钮 |
| 数据概览看板 `dashboard*` | `KpiRow`(`StatCard`×3~6) + `Card`（图表容器） + `Progress`/`RingProgress` + `DataTable`（明细） + `Segmented 时间范围（RadioGroup buttonStyle）` |
| 个人主页 / 用户设置 `user-home` / `user-setting` | `PageHeader` + `Tabs` + `Card` + `Descriptions` + `FormField` + `Avatar` + `Upload`（头像） |
| 登录 / Banner / 分栏登录 `login*` | `Card`（居中，宽 360~420） + `FormField` + `Input` + `CheckboxGroup` + `Button block` + `Alert`（错误提示） |
| 消息 / 通知列表 | `Tabs` + `List`+`ListItem` + `Badge count` + `Empty` |
| 订单管理列表 `order-list` | `FilterBar` + `OrderTable`（内置状态列/金额列）+ `OrderStatusFlow`（可选，行内速览）+ `Pagination` |
| 订单详情 / 交易详情 `order-detail` | `PageHeader` + `OrderDetailHeader` + `Tabs`（商品明细/履约进度/操作轨迹） + `OrderItemList` + `OrderStatusFlow` + `OrderTimeline` + `OrderAmountSummary` |
| 收银台 / 结算页 `payment-cashier` | `PaymentCashier`（整块：摘要+金额+支付方式+倒计时+支付按钮）；或拆开用 `OrderAmountSummary` + `PaymentMethodPicker` + `PaymentCountdown` + `Button` |
| 支付结果页 `result-pay` | `PaymentResult state="success\|fail\|pending"` + `Button` 操作组 |
| 发票信息 `invoice` | `InvoiceForm` + `Modal`（或独立 `Card`） |
| 自动化规则列表 `automation-list` | `FilterBar` + `Grid(cols=2/3)` + `TriggerRuleCard` + `Empty` |
| 自动化规则编辑 `automation-edit` | `Steps`（触发/条件/动作）或 `Tabs` + `TriggerTypePicker` + `TriggerConditionBuilder` + `TriggerActionList` + `FormActions` |
| 内容管理列表 `cms-list` | `FilterBar` + `ContentTable` + `Pagination` + `PublishSchedulePanel`（发布弹窗内） |
| 内容编辑 `cms-edit` | `PageHeader` + `ContentEditorForm`（元信息，左/上） + `RichTextEditor`（正文） + `PublishSchedulePanel`（右侧/底部） + `MediaPicker`（封面向导，放 `Modal`） |
| 内容版本对比 `cms-diff` | `PageHeader` + `ContentVersionDiff` + `Timeline`（版本历史） |
| 工作流列表 `workflow-list` | `FilterBar` + `WorkflowList` + `Pagination` |
| 工作流设计器 `workflow-designer` | `NodePalettePanel`（左）+ `WorkflowCanvas`（中，**需 `@xyflow/react`**）+ 右侧属性面板（`FormField`/`ApprovalNodeCard`） |
| 工作流执行详情 `workflow-run` | `PageHeader` + `ExecutionLogTimeline` + `Descriptions`（实例基础信息）+ `ResultPage`（整体成败） |

## 2. 模块级映射（页内局部）

| 页面模块 | 用什么组件 | 备注 |
| --- | --- | --- |
| 页面标题区 | `PageHeader`（+`Breadcrumb`） | 标题不重复出现在卡片内 |
| 顶部 KPI 区 | `KpiRow` + `StatCard` | 3~6 张卡，`tone` 表语义（success/warning/danger） |
| 筛选区（多条件） | `FilterBar` + `FormField` 包 `Input`/`Select`/`RangePicker` | 超过一行自动折叠，查询=主按钮 |
| 筛选区（少量标签） | `FilterBarInline` + `RadioGroup buttonStyle` | 时间范围、状态切换 |
| 工具栏 | `Toolbar`（TableCard 已内置） | 左主操作、右搜索/刷新 |
| 数据表格 | `DataTable` + `Tag`/`StatusTag` | 操作列 `align="right"` 固定最右 |
| 分页 | `Pagination`（TableCard 已内置） | 默认 10/20/50 条每页 |
| 状态列 / 状态字段 | `StatusTag` + `STATUS_PRESETS` | 集中映射，勿各页写死颜色 |
| 只读详情字段 | `Descriptions`（`column=2/3`） | 状态值传 `StatusTag` |
| 新增/编辑表单 | `Modal`（轻量）或页面级 `Card`+`FormField`+`FormActions` | 字段多/分组 → 独立页面；≤6 字段 → `Modal`/`Drawer` |
| 详情速览 | `Drawer` + `Descriptions` | 保留列表上下文 |
| 删除/停用等破坏性操作 | `ConfirmModal danger` + `message.success` | 必须二次确认 |
| 加载态 | 首次 `Skeleton variant="table\|list\|card"`；局部 `Spin` | 避免白屏与布局跳动 |
| 空态 | `Empty` + 下一步按钮 | 未配置/无结果显示 action |
| 长文本/超长列 | `Tooltip` 或 `Text ellipsis` | 超长单元格给 Tooltip |
| 操作反馈 | `message.success/error` + 根组件挂 `<MessageHost />` | 不打断操作 |
| 风险/规则提示 | `Alert type="info\|warning\|error"` | 表单顶部说明、校验失败汇总 |

## 4. 反模式（不要这样做）

| 反模式 | 正确做法 |
| --- | --- |
| 页面里手写 `<table>` / 自定义按钮样式 | 用 `DataTable` / `Button` |
| 状态用 Switch 表达 | 用 `Tag` / `StatusTag` |
| 每个页面各写一套状态色 if/else | 用 `STATUS_PRESETS` + `StatusTag` |
| 用连续 margin 凑间距 | 用 `Space` / `Grid` / `Row·Col` |
| 弹窗手写 fixed 层 | 用 `Modal` / `Drawer` / `ConfirmModal` |
| 表格加载用文字「加载中」 | 用 `Skeleton`（首次）/ `Spin`（局部） |
| 删除无二次确认 | `ConfirmModal danger` |
| 从 arco/antd 引入组件 | 本库零依赖，复制即用，勿引第三方 UI 库 |

## 5. 长尾与图表场景（第二批）

| 场景 | 用什么组件组合 |
| --- | --- |
| 任意图表（折线/柱状/饼环） | `ChartCard`（标题+单位+统计周期）包 `LineChart`/`AreaChart`/`BarChart`/`PieChart`/`DonutChart`；KPI 卡内走势用 `Sparkline` |
| 看板 / 任务流转 | `Kanban`（列=状态）+ `Tag`/`Avatar`/`Progress` 卡片内容 |
| 操作日志 / 审批流 / 里程碑 | `Timeline`（配合 `Card` 或 `Collapse`） |
| 详情页多分区 | `Collapse`（主分区默认展开）+ `Descriptions` |
| 排期 / 值班 / 变更窗口 | `Calendar`（`marks` 打点）+ 右侧 `List` 事件清单 |
| 权限 / 角色分配 | `Transfer`（左侧待选、右侧已选） |
| 行政区划 / 组织层级 / 多级分类 | `Cascader`（≥2 级）；只需选一个节点用 `TreeSelect` |
| 阈值 / 权重调节 | `Slider`（配合 `InputNumber` 精确输入） |
| 满意度 / 优先级打分 | `Rate`（只读展示传 `readOnly`） |
| 联想输入（项目名/负责人） | `AutoComplete` |
| 评论 / 工单 @成员 | `Mention` |
| 短信验证码 / 二次校验 | `VerificationCode`（整段粘贴自动分配） |
| 登录 / 改密 | `PasswordInput`（含强度条）+ `Alert`（错误提示） |
| 表格内轻量删除确认 | `Popconfirm danger`（比 Modal 轻，不打断整页） |
| 导入结果 / 后台任务反馈 | `notification.xxx({title,desc})` + 根组件 `<NotificationHost />` |

### 图表规范（硬性，来自用户图表通用规范）
1. 标题在**图表区顶部**；副标题/单位/时间范围作为元数据放标题旁或下方
2. 单位紧邻标题下方「单位：xxx」，**加粗主色**区分；单位约定：震动=g、长度=mm、应力=MPa、温度=℃、应变=με、百分比=%
3. 多系列**必须**有图例，且**可点击切换显隐**
4. **统计周期单选放标题旁**（近7天/近30天/今年）
5. x-y 关系图有网格、轴标签、刻度
6. **禁止**在图内塞「X 轴·近XX小时级·Y 轴单位·xx」这类串词

## 6. 业务场景组件映射（第三批 · 2026-09-19）

> 第三批为**业务场景级**组件（订单/付款/触发器/CMS/工作流），共 27 个，直接对应真实业务页面。
> **依赖提醒**：其中 26 个零依赖；`WorkflowCanvas` **依赖 `@xyflow/react@^12`**，须 `npm i @xyflow/react` + `import '@xyflow/react/dist/style.css'`，并**按路径引入**（不在统一出口）。

### 6.1 模块级映射

| 业务模块 | 用什么组件 | 备注 |
| --- | --- | --- |
| 订单列表表格 | `OrderTable` | 内置编号/客户/件数/金额/状态/时间六列，状态走 `ORDER_STATUS_PRESETS` |
| 订单状态展示 | `StatusTag` + `ORDER_STATUS_PRESETS.order` | 简版三态用 `.simple`；文案取中文用 `orderStatusText()` |
| 订单详情头部 | `OrderDetailHeader` | 订单号+状态+金额大字+关键字段+操作区 |
| 商品/退款明细 | `OrderItemList` | 表尾合计由组件自动包合法行；行操作走 `renderActions` |
| 履约进度 | `OrderStatusFlow` + `ORDER_FLOW_STEPS` | `error`=某步异常；`closed`=提前终止（整体置灰+原因），**两者都不等于「全部完成」** |
| 操作日志（业务单据） | `OrderTimeline` + `TRACE_COLORS` | 默认**倒序**（最新在上） |
| 金额明细 | `OrderAmountSummary` | 小计/优惠/运费/应付；减项传负数自动显红 |
| 收银台整块 | `PaymentCashier` | 需要拆开单用 → `OrderAmountSummary` + `PaymentMethodPicker` + `PaymentCountdown` |
| 支付渠道选择 | `PaymentMethodPicker` + `PAYMENT_METHOD_PRESETS` | **不接真实支付 SDK**；选中态主色描边+对勾，不用 Radio |
| 支付倒计时 | `PaymentCountdown` | 内部是真实计时器，**业务侧不要再手写 setInterval** |
| 支付结果 | `PaymentResult` + `PaymentResultState` | success/fail/pending 三态，可嵌 Modal |
| 开票信息 | `InvoiceForm` | 个人/普票/专票；**专票才要地址电话开户行账号** |
| 自动化规则卡片 | `TriggerRuleCard` + `TRIGGER_RUN_PRESETS` | 启停 Switch + 命中次数 + 最近执行结果 |
| 触发方式 | `TriggerTypePicker` + `TRIGGER_TYPE_PRESETS` | 卡片单选（视觉同支付方式选择） |
| 条件组 | `TriggerConditionBuilder` + `TRIGGER_OPERATORS` | 字段-运算符-值 行式 + 且/或切换 |
| 动作序列 | `TriggerActionList` | **列表顺序即执行顺序**，支持上移/下移/删除 |
| 内容列表 | `ContentTable` | 置顶/推荐标记内嵌标题列，不另开列 |
| 内容状态 | `ContentStatusBadge` + `CONTENT_STATUS_PRESETS` | `.full` 七态 / `.simple` 三态 |
| 内容元信息 | `ContentEditorForm` | 只管标题/摘要/栏目/标签/封面；正文另接 `RichTextEditor` |
| 正文富文本 | `RichTextEditor` + `RICH_TEXT_TOOLS` | 轻量版（contentEditable + execCommand），**无 XSS 过滤、不适合生产环境**；落库前需自行净化 |
| 版本差异 | `ContentVersionDiff` + `diffLines`/`diffStat` | 零依赖 LCS 逐行 diff，大文本自动降级 |
| 素材选择 | `MediaPicker` + `MediaItem` | 常放 `Modal`（宽 720+）；**无图时不要塞假 URL**，不传 `url` 渲染占位块 |
| 发布设置 | `PublishSchedulePanel` | 立即/定时 + 发布范围 + 发布端 |
| 流程列表 | `WorkflowList` + `WORKFLOW_STATUS_PRESETS.flow` | key 以等宽字体显示在名称下 |
| 节点库 | `NodePalettePanel` | 拖拽 `dataTransfer` 键固定 `application/x-workflow-node` |
| 工作流画布 | `WorkflowCanvas` + `WORKFLOW_NODE_TYPES` | ⚠️ **需 `@xyflow/react`**，按路径引入 |
| 执行日志 | `ExecutionLogTimeline` + `EXECUTION_STATUS_PRESETS.run` | **执行顺序（最早在上）**，与订单轨迹相反 |
| 审批节点 | `ApprovalNodeCard` + `APPROVAL_STATUS_PRESETS` | 同一组件兼顾配置态（`editable`）与运行态（`status`） |

### 6.7 第三批反模式（补充）

| 反模式 | 正确做法 |
| --- | --- |
| 页面里自己写 `setInterval` 做起倒计时 | 用 `PaymentCountdown`（内置真实计时器） |
| 已取消订单把 `current` 传成 steps.length 表示「终止」 | 用 `closed` + `closedReason`，`current` 保持真实值 |
| 给 `OrderItemList` 的 `summary` 自己包一层 `<div>` | 直接传合法 `<tr><td colSpan>`，或交给组件自动包 |
| 素材库没有图片时塞假图 URL / placeholder 图床 | 不传 `url`，组件渲染占位块 |
| 把 `RichTextEditor` 当生产级编辑器用于公网用户内容 | 它是原型级实现，无 XSS 过滤；生产需换专业编辑器或严格净化 |
| 引用锚点在长页面上无效 | 预览用 `?only=<分区id>` 单区聚焦模式截图，而非依赖锚点滚动 |
| 在不需要画布的页面也从统一出口 import 导致拉入 `@xyflow/react` | `WorkflowCanvas` 按路径单独引入；不要把它加进 barrel 出口 |
