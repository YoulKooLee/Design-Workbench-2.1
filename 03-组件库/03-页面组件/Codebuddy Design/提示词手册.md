# 组件提示词手册（复制即用）

> 用法：绘制原型时，把对应组件的提示词**整段复制**给智能体（或在面板「组件库」页签点「复制提示词」），
> 智能体即可按统一约定引用该组件，**不要自造同类样式**。
> 前置：先把 `03-组件库\03-页面组件\Codebuddy Design\` 整体复制到工程的 `src/component-templates/axhub/`（见 README §3）。

---

## base · 基础

### Button 按钮
【组件引用】Button 按钮（组件库 基础）
用法：`import { Button, ButtonGroup } from '../component-templates/axhub'`
参数：`variant` primary|secondary|outline|text|danger|success|warning；`size` sm|md|lg；`loading`；`icon`；`ghost`；`block`
场景：页面主/次操作、工具栏、表单提交、弹窗底部（主操作放最右）。不要自造按钮样式。

### Card / SectionCard 卡片
【组件引用】Card 卡片（组件库 基础）
用法：`import { Card, SectionCard } from '../component-templates/axhub'`
参数：`title`；`extra`（右上操作）；`bordered`；`flush`（嵌表格/列表时去内边距）；SectionCard 另有 `desc`
场景：页面区块容器、表格/表单外包、看板分区。列表页用 `flush` 包 DataTable。

### Tag 标签
【组件引用】Tag 标签（组件库 基础）
用法：`import { Tag } from '../component-templates/axhub'`
参数：`color` blue|green|orange|red|gray|purple|cyan；`closable`+`onClose`；`dot`
场景：状态/分类/属性标识、筛选回显。**只读状态不要用 Switch 表达**。

### Badge 徽标 / 状态点
【组件引用】Badge 徽标（组件库 基础）
用法：`import { Badge } from '../component-templates/axhub'`
参数：`status` default|processing|success|warning|danger + `text`（状态点模式）；`count` + `children`（角标模式）
场景：表格状态列、通知计数角标。

### Avatar / AvatarGroup 头像
【组件引用】Avatar 头像（组件库 基础）
用法：`import { Avatar, AvatarGroup } from '../component-templates/axhub'`
参数：`src`；`name`（无图时取名称生成文字头像）；`size` xs|sm|md|lg；`shape` circle|square
场景：表格负责人列、顶部账号、评论/动态、成员管理。

### Title / Text / Paragraph 文本
【组件引用】Typography 文本（组件库 基础）
用法：`import { Title, Text, Paragraph } from '../component-templates/axhub'`
参数：Title `level` 1-5；Text `type` primary|secondary|success|warning|danger|disabled、`bold`、`ellipsis`、`code`
场景：页面/区块标题、表格次要信息、错误文案、编号等宽显示。次要信息统一 `type="secondary"`。

### Divider 分割线
【组件引用】Divider 分割线（组件库 基础）
用法：`import { Divider } from '../component-templates/axhub'`
参数：`direction` horizontal|vertical；`align` left|center|right；可传 children 显示中间文字
场景：表单分区之间、详情字段组之间、工具栏按钮组之间。

### Tooltip / Dropdown / Popover 浮层
【组件引用】浮层组件（组件库 基础）
用法：`import { Tooltip, Dropdown, Popover } from '../component-templates/axhub'`
参数：Tooltip `content`+`placement`；Dropdown `trigger`+`items`[{key,label,icon,danger,dividerBefore}]+`onSelect`；Popover `content`+`triggerMode`
场景：图标按钮释义、表格操作列「更多」、头部账号菜单、轻量设置面板。

## layout · 布局

### Space / Row·Col / Grid 排版
【组件引用】排版栅格（组件库 布局）
用法：`import { Space, Row, Col, Grid } from '../component-templates/axhub'`
参数：Space `size` xs|sm|md|lg|数字、`direction`、`wrap`；Col `span`（24 栅格）；Grid `cols` 1|2|3|4|6、`gap`
场景：按钮间距、表单一列/两列布局、卡片等宽网格。禁止用连续 margin 手工凑间距。

### PageHeader 页面头
【组件引用】PageHeader 页面头（组件库 布局）
用法：`import { PageHeader, Breadcrumb } from '../component-templates/axhub'`
参数：`title`；`desc`；`breadcrumb`；`onBack`；`extra`（右侧操作）；`footer`
场景：详情页/表单页/复杂列表页顶部 —— 标题 + 说明 + 面包屑 + 操作区。标题不要在卡片里重复。

### Tabs 标签页
【组件引用】Tabs 标签页（组件库 布局）
用法：`import { Tabs } from '../component-templates/axhub'`
参数：`items`[{key,label,children,disabled}]；`defaultActiveKey`；`type` line|card|capsule；`centered`
场景：设置页分组、详情页信息分区、看板视图切换。同级视图切换用 Tabs，跨页跳转用菜单。

### Steps 步骤条
【组件引用】Steps 步骤条（组件库 布局）
用法：`import { Steps } from '../component-templates/axhub'`
参数：`items`[{title,desc}]；`current`；`direction` horizontal|vertical；`status` process|error
场景：分步表单、导入向导（上传→校验→结果）、流程进度。

### Toolbar 工具栏
【组件引用】Toolbar 工具栏（组件库 布局）
用法：`import { Toolbar } from '../component-templates/axhub'`
参数：`left`（主操作，如「新增/批量导入」）；`right`（搜索、筛选、刷新）；`divider`
场景：列表页/表格卡片顶部操作条。不要每页手写 flex 排布。

## form · 表单

### FormField / FormRow / FormActions 字段容器
【组件引用】FormField 字段容器（组件库 表单）
用法：`import { FormField, FormRow, FormActions } from '../component-templates/axhub'`
参数：FormField `label`/`required`/`hint`/`error`/`horizontal`/`labelWidth`；FormRow `cols` 1|2|3；FormActions `align`
场景：所有表单与筛选区的字段包装。字段一律用它包，不要裸写 label + input；校验错误用 `error` 传入。

### Input / Textarea / InputNumber / SearchBar 输入
【组件引用】输入组件（组件库 表单）
用法：`import { Input, Textarea, InputNumber, SearchBar } from '../component-templates/axhub'`
参数：Input `prefix`/`suffix`/`allowClear`/`error`；Textarea `showCount`+`maxLength`；InputNumber `min`/`max`/`step`/`controls`；SearchBar `onSearch`+`width`
场景：文本输入、备注、数量/金额/阈值、列表页搜索框。

### Select 下拉选择
【组件引用】Select 下拉（组件库 表单）
用法：`import { Select } from '../component-templates/axhub'`
参数：`options`[{label,value,disabled}]；`mode` single|multiple；`value`/`onChange`；`allowClear`；`placeholder`；`error`
场景：筛选条件（状态/类型）、表单枚举字段。选项 ≤5 且需常显时改用 RadioGroup。

### RadioGroup / CheckboxGroup / Switch 选择开关
【组件引用】单选多选开关（组件库 表单）
用法：`import { RadioGroup, CheckboxGroup, Switch } from '../component-templates/axhub'`
参数：RadioGroup `options`/`direction`/`buttonStyle`（分段控件）；CheckboxGroup `options`/`selectAll`；Switch `checked`/`onChange`/`size`
场景：状态选择、类型切换、多条件筛选、启用停用开关。**开关不用于只读状态展示**。

### DatePicker / RangePicker / TimePicker 日期时间
【组件引用】日期组件（组件库 表单）
用法：`import { DatePicker, RangePicker, TimePicker } from '../component-templates/axhub'`
参数：DatePicker `mode` date|datetime；RangePicker 默认带「近 7 天/近 30 天/今年」快捷项；TimePicker `HH:mm`
场景：单据日期、统计区间筛选、执行时刻。

### Upload 上传
【组件引用】Upload 上传（组件库 表单）
用法：`import { Upload, type UploadFile } from '../component-templates/axhub'`
参数：`mode` list|drag；`accept`；`files`+`onChange`（父级负责真实上传）；`onRemove`；`maxCount`；`hint`
场景：导入 Excel、附件/图片上传、导入向导第一步。

## data · 数据展示

### DataTable 表格
【组件引用】DataTable 表格（组件库 数据展示）

### Pagination 分页
【组件引用】Pagination 分页（组件库 数据展示）
用法：`import { Pagination } from '../component-templates/axhub'`
参数：`current`/`pageSize`/`total`/`onChange(page,pageSize)`；`pageSizeOptions`；`showTotal`；`align`
场景：表格底部（TableCard 已内置，独立用时放卡片右下）。

### Descriptions 描述列表
【组件引用】Descriptions 描述列表（组件库 数据展示）
用法：`import { Descriptions } from '../component-templates/axhub'`
参数：`items`[{label,value,span}]；`column` 1|2|3|4；`bordered`；`layout` horizontal|vertical；`labelWidth`
场景：详情页只读字段区。状态类字段值传 `<StatusTag />`。

### Progress / RingProgress 进度
【组件引用】Progress 进度（组件库 数据展示）
用法：`import { Progress, RingProgress, autoStatus } from '../component-templates/axhub'`
参数：`percent`；`status` 或 `autoStatus(percent)`；`height`；RingProgress `size`/`thickness`/`text`
场景：任务完成率、导入进度、指标达成率。达成率建议用 `autoStatus` 自动取色。

### List / ListItem 列表
【组件引用】List 列表（组件库 数据展示）
用法：`import { List, ListItem } from '../component-templates/axhub'`
参数：ListItem `avatar`/`title`/`desc`/`extra`/`footer`/`onClick`；List `bordered`/`split`/`empty`
场景：消息通知、动态流、待办、搜索结果、主从分栏左列表。

### Tree 树形导航
【组件引用】Tree 树（组件库 数据展示）
用法：`import { Tree, type TreeNode } from '../component-templates/axhub'`
参数：`data`；`selectedKey`+`onSelect`；`searchable`；`defaultExpandAll`
场景：左树右表（分类/组织/目录 + 明细）、素材库目录。

## feedback · 反馈

### Modal / ConfirmModal 弹窗
【组件引用】Modal 弹窗（组件库 反馈）
用法：`import { Modal, ConfirmModal } from '../component-templates/axhub'`
参数：Modal `open`/`onClose`/`title`/`width`/`footer`/`maskClosable`(默认 false 防误关，Esc 可关)；ConfirmModal `danger`/`content`/`onOk`/`loading`
场景：表单新增编辑、确认操作、详情速览。破坏性操作前必须用 ConfirmModal 二次确认。

### Drawer 抽屉
【组件引用】Drawer 抽屉（组件库 反馈）
用法：`import { Drawer } from '../component-templates/axhub'`
参数：`open`/`onClose`/`title`/`width`(默认 480)/`footer`/`placement` right|left
场景：详情速览（不跳页）、编辑表单、筛选/配置面板。保留列表上下文用 Drawer，强打断用 Modal。

### Alert 提示条
【组件引用】Alert 提示条（组件库 反馈）
用法：`import { Alert } from '../component-templates/axhub'`
参数：`type` info|success|warning|error；`title`；`closable`；`action`；`bordered`
场景：表单说明、校验失败原因汇总、数据异常/风险提示。

### Spin / Skeleton / Empty 加载与空态
【组件引用】加载与空态（组件库 反馈）
用法：`import { Spin, Skeleton, Empty } from '../component-templates/axhub'`
参数：Spin `tip`/`size`/`fullscreen`；Skeleton `variant` text|card|table|list + `rows`；Empty `desc`+`action`
场景：局部加载用 Spin；首次加载占位用 Skeleton（避免白屏跳动）；无结果/未配置用 Empty（尽量给 action）。

### ResultPage 结果页
【组件引用】ResultPage 结果页（组件库 反馈）
用法：`import { ResultPage } from '../component-templates/axhub'`
参数：`status` success|error|warning|waiting|403|404|500；`title`/`desc`/`actions`/`extra`
场景：提交成功、操作失败、审批等待、异常页。success 后给下一步按钮；error 必须给原因与重试入口。

### message 轻提示
【组件引用】message 轻提示（组件库 反馈）
用法：`import { message, MessageHost } from '../component-templates/axhub'`；页面根组件挂一次 `<MessageHost />`，任意处调用 `message.success('保存成功')`
场景：保存/复制/校验结果的轻量反馈（不打断操作）。需用户确认时用 ConfirmModal。

## business · 业务组件

### StatCard / KpiRow 指标卡
【组件引用】指标卡（组件库 业务组件）
用法：`import { StatCard, KpiRow } from '../component-templates/axhub'`
参数：StatCard `label`/`value`/`trend`/`trendUp`/`trendLabel`/`icon`/`tone`/`footer`；KpiRow `cols` 2|3|4|6

【组件引用】FilterBar 筛选栏（组件库 业务组件）

### TableCard / DetailCard 列表页与详情页骨架
【组件引用】TableCard 列表页骨架（组件库 业务组件）

### StatusTag 状态标签
【组件引用】StatusTag 状态标签（组件库 业务组件）
用法：`import { StatusTag, STATUS_PRESETS } from '../component-templates/axhub'`
参数：`value` + `map`；预设：`STATUS_PRESETS.enabled / .approval / .task / .health`；`fallback`/`passthrough`
场景：表格状态列、详情页状态字段。把状态码统一映射为中文+颜色，**不要在页面里写死颜色 if/else**。

## 长尾扩展（第二批 · 2026-09-17）

## 业务场景组件（第三批 · 2026-09-19）

> 本批为**业务场景级**组件（订单 / 付款 / 触发器 / CMS / 工作流），直接对应真实业务页面。
> 与 `business · 业务组件` 的区别：business 是「页面骨架与通用件」，本批是「带业务语义的组装件」（金额、状态流转、收银台、条件规则、版本差异等）。
> **依赖说明（重要）**：本批 27 个组件中 **26 个零第三方依赖**；**唯一例外是 `WorkflowCanvas`，它依赖 `@xyflow/react`**，因此**不在统一出口导出**，须按路径单独引入（见下）。
