## 建议直接搬进现有库的 5 个（性价比最高）

| 组件 | 为什么值得搬 | 预计代码量 |
| --- | --- | --- |
| `mockup-browser` / `mockup-window` / `mockup-phone` / `mockup-code` | 提案页最缺的就是「情境外框」，截图放进去可信度立刻上一个档 | 约 150 行 CSS |
| `diff` | 改版前后、换肤前后对比，拖动即可，比做两张图更有说服力 | 约 80 行 |
| `theme-controller` | 主题切换只需要 radio 的 value，免 JS 状态机 | 约 30 行 |
| `stat` / `stats` | KPI 条已经有一版，但 daisyUI 的横向/纵向切换更省事 | 约 60 行 |
| `aura` / `hover-3d` | 静态截图“活”起来的低成本手段（注意：**页面内 aura 只用一处**） | 约 120 行 |

## 不建议搬的

- `table` / `pagination` / `select`：现有 DataTable、Pagination、Select 的能力明显更强，搬过来是降级。
- `calendar`：daisyUI 只给 Cally / DayPicker 做皮肤，本身不带日历逻辑。
- `filter` / `list` / `menu`：和现有 FilterBar / List / SideMenu 定位重叠，混用会出现两套交互习惯。
