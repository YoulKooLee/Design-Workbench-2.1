# design-notes 设计说明模块补丁

**版本 v3.0 · 2026-11-03**｜基线实现：指标管理平台 `src/prototypes/indicator-platform/design-notes/`

用途：为原型页面提供右侧设计说明面板（单卡双页签 + SVG 连线 + 悬停高亮 + 富文本编辑 + 状态标记 + 收起展开 + 新增/编辑/删除 + 数据落盘），视觉风格为微软 Fluent（白卡细描边浅阴影、#0067b8 主色、底部链接式操作行）。

## 怎么用（先读这节）

### AI 画原型时的固定三步（顺序不能反）

1. **先打标**：生成页面 JSX 时，给每个可独立说明的区块加 `data-proto-id` + `data-proto-label`。弹窗 / 页签里的区块，标打在弹窗内容根元素上。
2. **再关联卡片**：在真源（如 `buildModules`）里为本页建设计说明卡片，每张卡 `bind` 指向一个区块 id；来不及写说明的先建**空卡片**（显示「＋ 待补充说明」占位）。
3. **按设计文档写说明**：一张卡内部写两类说明——**页面说明**（必填：结构 / 字段口径 / 交互 / 校验 / 状态边界 / 本期不做）与**接口说明**（可选 `apiRich`：请求响应 / 绑定表 / 批次规则 / 错误码 / 报文样例）；写不完的留空卡，同一对话里后续让 AI 补。

命名规则、必标区块清单、提示词模板与自查清单见 **`assets/规范.md` Part B**；**一张卡写什么、两类说明各填哪些要点、内容来源红线（§8.1）**见 **`assets/规范.md` Part C**。三份文档已于 v3.0 合一，`规范.md` 是唯一真源。

### 人怎么用面板（一分钟上手）

- 悬浮左侧已打标区域：未写说明 → 蓝「**+ 说明**」点击建卡；已写 → 绿「**✓ 已说明**」点击跳到卡片。
- 一张卡对应页面上一个区块：默认显示**页面说明**；两类说明都有内容的卡片多一个「**接口说明 API**」页签可切换，只有一类直接展示（不出页签）。
- 卡片底部是「**✎ 编辑说明**」链接行（微软卡片页脚风格）；**关联了哪个页面模块、删除操作都在编辑弹窗里**（连线本身就是关联的表达）。
- 编辑弹窗内也有「页面说明 / 接口说明」小节页签：两个文本域**等高 280px 固定**、超出各自滚动，写作引导句放在空态占位符里；页面说明用完整工具栏，接口说明只用精简工具栏（加粗 / 列表 / 清除格式）。
- 删除卡片：编辑弹窗左下「**删除这张卡片**」→ 弹窗内**二次确认**（取消可回到继续编辑），确认后才真正删除——落盘模式会直接改源码。
- 卡片可以先放空，之后点卡片补写，或直接在对话里让 AI 按区域补上。
- 编辑弹窗里可加粗 / 变色 / 加项目符号、选状态（设计中/已评审/待开发/开发中/已完成）、选关联模块。**关联选择器**带搜索框；下拉分两组——「当前视图可见」选中即连线，「本页识别过」是此前在本页打开过弹窗 / 页签时记住的区域（按页签隔离存储，选中后打开对应视图即连线）；找不到时用「＋ 手动填写区域 ID」直接填 `data-proto-id`。

## v2.2 相对 v2.1 的变更

- **单卡双页签**：一张卡 = 一个区块的页面说明 + 可选接口说明；`ModuleDef` 新增 `apiRich` 字段（受限 HTML），卡片与编辑弹窗都带「页面说明 / 接口说明 API」页签，页签只在两类内容都存在时出现（只有一类直显，规范见《设计说明卡片编写规范-单卡双页签.md》）
- **编辑弹窗改版**：固定高度三段式；双说明区弹窗页签切换、双文本域等高 280px 滚动、写作引导句进占位符；接口说明用精简工具栏
- **微软 Fluent 风格美化**：卡片改白底细描边 + 浅阴影（去掉彩色左边条）、主色 #0067b8、卡片底部操作行「✎ 编辑说明」蓝色链接（对齐微软账户页卡片页脚）；弹窗、状态选择器、删除确认、连线与悬浮徽章同步换肤
- **落盘适配器**：序列化字段顺序补 `apiRich`（id / title / status / bind / text / rich / apiRich / list）

## v2.1 相对 v2.0 的变更

- **卡片精简**：只保留「序号 + 标题 + 状态 + 内容 + 编辑」，关联信息（🔗 模块名 / ◇ 在弹窗中）不再占卡片版面，统一进「✎ 编辑」弹窗，并新增三态提示条（已关联 / 未渲染 / 未关联）
- **删除收进编辑弹窗**：弹窗左下「删除这张卡片」→ 弹窗内二次确认（取消可回到继续编辑），防误删（落盘模式删除会直接改源码）
- **修复「删除又回来」**：落盘成功后保留乐观视图、等真源热更新追平再收敛；此前落盘成功立即回退静态真源，刚删的卡片会重新出现
- 文档新增「AI 三步法」使用说明（README / 规范.md / 打标规范 v1.1 / 接入手册同步更新）

## v2.0 相对 v1.0 的新增

- 富文本单框编辑：正文与要点合并为一个编辑框，工具栏一排 6 控件（加粗 / 斜体 / 下划线 ｜ 字体颜色 ｜ 项目符号 ｜ 清除格式），保存时按内容自动分流 `rich` 或 `text`+`list`
- 状态标记：设计中 / 已评审 / 待开发 / 开发中 / 已完成，卡片胶囊 + 面板汇总
- 面板收起 / 展开（54px 竖排标签，localStorage 记忆）
- 空卡片占位「＋ 待补充说明」，支持先占位后由人或 AI 补写
- 悬停双态徽章：未写 → 蓝「+ 说明」，已写 → 绿「✓ 已说明」跳卡
- `MutationObserver` 动态 DOM 重绘：弹窗 / 页签 / 步骤条打开后自动补连线
- `bind` 一对多：同一区域允许多张卡片，不再静默清空重复绑定
- 落盘适配器增强：`?raw` 单遍反转义、子页缺失直接报错、空块串页防护、缩进对齐、字段顺序固定

## 落点与生效方式

- 新建项目自动携带本补丁（`apply-project-patches.mjs`），存量项目可手动复制三个代码文件或重跑补丁脚本。
- 页面侧必须按《设计说明打标规范.md》给区块打 `data-proto-id` + `data-proto-label`，否则面板扫不到、无法连线。
