# 设计说明模块 · 规范与接入手册

> 适用范围：结构监测工作台「设计说明（DESIGN NOTES）」模块的可复用打包件。
> 本模块为原型页面提供**右侧设计说明面板**：Xbox 风格编号卡片 + SVG 连线 + 悬停高亮 + 新增/编辑/删除 + 数据落盘（可注入）。
> 源实现位于结构监测项目 `src/common/StructureMonitorShell.tsx` 的 `sm-right` 段；本打包件已与其解耦，可复制到任意 React 项目。

---

## 1. 能力清单

| 能力 | 说明 |
| --- | --- |
| Xbox 风格编号卡片 | 右侧白底蓝边卡片，左上角序号 + 标题，正文/要点列表展示 |
| SVG 链接线 | 关联模块时，左侧页面元素 → 右侧卡片自动画贝塞尔连线，线中点显示卡片序号 |
| 悬停高亮联动 | 悬停左/右任一模块，对应另一侧元素 + 连线同时高亮 |
| 新增 / 编辑 / 删除模块 | 弹窗编辑（标题、说明文本、要点列表、关联左侧模块）；右侧「+ 添加模块」或左侧悬停「+ 加说明」快捷入口 |
| 关联页面模块 | 编辑时选择 `bind` 到左侧带 `data-proto-id` 的元素，自动生成连线；同一元素可被多张卡片关联 |
| 数据落盘（可注入） | 编辑结果通过 `onSave` 回调写回真源；无适配器时降级为 localStorage 本地草稿 |
| 草稿兜底与容错 | 落盘前先写 localStorage；落盘失败保留草稿并提示「⚠ 落盘失败」，数据不丢 |
| 重置 | 放弃未落盘修改，回退到真源版本 |

## 2. 数据契约

### 2.1 模块卡片 `ModuleDef`

```ts
type ModuleDef = {
  id: string;            // 稳定唯一 id；新增卡片形如 custom-<timestamp>
  title: string;         // 卡片标题
  text?: string;         // 说明正文（支持换行）
  list?: string[];       // 要点列表（可为空）
  bind?: string;         // 关联的左侧页面模块 id（对应 data-proto-id）；为空则不连线
};
```

### 2.2 页面侧约定（宿主需满足）

- **左侧主内容区**内，任意可独立说明的区域打上 `data-proto-id="<模块id>"`（可选 `data-proto-label="可读名"`，用于下拉与卡片标签；不写则自动取标题文本 / 首段文字）。
- 设计说明面板与左侧内容需处于**同一水平可视范围**（连线基于 `getBoundingClientRect` 定位，`position:fixed` 的 SVG 全屏覆盖）。
- 窄屏（≤900px）连线自动隐藏（CSS `@media`）。

### 2.3 源码真源约定（落盘到 Axhub 原型源码时）

- 每个原型页面 `src/prototypes/<pageKey>/index.tsx` 内含 `function buildModules(...)`，返回一个 `ModuleDef[]`。
- 子页（二级子页签）用 `if (sub === '<pageSub>') { return [ ... ] }` 分支；默认分支位于函数末尾。
- 落盘适配器据此定位对应 `return [ ... ]` 块做整块替换（见 §4）。

## 3. 组件接入

### 3.1 文件清单

```
设计说明模块/
  DesignNotesPanel.tsx   // 主组件（零 Axhub 依赖，仅依赖 react）
  designNotesTypes.ts    // ModuleDef / DesignNotesSaveAdapter / DesignNotesSaveMeta
  axhubSaveAdapter.ts    // Axhub 落盘参考实现（?raw + /api/text-replace/replace），可照搬或改写
  规范.md                // 本文件
```

### 3.2 最简用法（本地草稿模式，不落盘）

```tsx
import { useRef } from 'react';
import { DesignNotesPanel, type ModuleDef } from './设计说明模块/DesignNotesPanel';

const leftRef = useRef<HTMLDivElement>(null);
const modules: ModuleDef[] = [
  { id: 'kpi', title: '核心指标', text: '展示当日关键指标。', list: ['对接 /metrics', '待补单位字段'] },
  { id: 'chart', title: '趋势图', bind: 'trend-chart' },
];

<div style={{ display: 'flex' }}>
  <main ref={leftRef} style={{ flex: 1 }}>
    {/* 左侧内容；可关联区域打 data-proto-id */}
    <section data-proto-id="trend-chart">…趋势图…</section>
  </main>
  <DesignNotesPanel modules={modules} pageKey="dashboard" leftContentRef={leftRef} />
</div>;
```

### 3.3 落盘用法（注入 onSave 适配器）

```tsx
import { createAxhubDesignNotesAdapter } from './设计说明模块/axhubSaveAdapter';

const onSave = createAxhubDesignNotesAdapter(); // 默认对接 Axhub 预览服务
// 或自建适配器：
// const onSave = async (next, meta) => { await myApi.save(meta.pageKey, meta.pageSub, next); };

<DesignNotesPanel
  modules={modules}
  pageKey="diagnosis"
  pageSub="趋势分析"
  leftContentRef={leftRef}
  onSave={onSave}
/>;
```

### 3.4 子页切换时刷新连线

宿主切换二级子页后，左侧 DOM 变化，需让面板重扫连线与可绑定清单：改变 `contentKey` 属性即可。

```tsx
<DesignNotesPanel
  modules={modules}
  pageKey="dashboard"
  pageSub={activeSub}
  leftContentRef={leftRef}
  onSave={onSave}
  contentKey={`${activeSub}`}   // 子页变化时触发重扫
/>
```

## 4. Axhub 落盘参考实现（自建存储可照搬）

`axhubSaveAdapter.ts` 提供 `createAxhubDesignNotesAdapter()`，依赖 Axhub 预览服务两个接口：

1. **读取源码**：`GET /prototypes/<pageKey>/index.tsx?raw`
   - 返回该原型源码文本；预览服务对 `?raw` 有两种包裹（双引号 JSON / 反引号模板），适配器会分别剥离并完整反转义，恢复到与磁盘逐字节一致的文本——否则文本替换会因 CRLF/转义不匹配而 409 失败。
2. **文本替换**：`POST /api/text-replace/replace`
   - Body：`{ path: "prototypes/<pageKey>", replacements: [{ searchText: <原 return 块>, replaceText: <新 return 块> }] }`
   - 成功返回 `{ success: true }`。

内部流程：`fetch ?raw` → `extractReturnBlock(src, pageSub)` 定位 `return [ … ]` → 序列化为 `return [ … ]` 新文本 → `POST /api/text-replace/replace`。

> 其他项目若没有该预览服务，只需实现 `(next, meta) => Promise<void>`：把 `next` 写进自家真源（DB / 文件 / CMS）即可，组件本身零后端依赖。

## 5. 适配到其他项目 / 模板的清单

- [ ] 拷贝 `DesignNotesPanel.tsx` + `designNotesTypes.ts`（二者即最小可运行集）。
- [ ] 左侧内容区为可说明区域打 `data-proto-id`（建议同时写 `data-proto-label`）。
- [ ] 三栏布局里把面板挂右侧，传 `leftContentRef`、`pageKey`。
- [ ] 需要落盘：拷贝 `axhubSaveAdapter.ts` 并对接自家接口，或自己实现 `onSave`。
- [ ] 纯预览 / 暂存：不传 `onSave`，自动进入 localStorage 本地草稿模式。
- [ ] 子页签切换时传 `contentKey` 触发连线重扫。

## 6. 已知约束 / 踩坑

- **预览服务需提供 `/api/text-replace/replace` 与 `?raw`**，否则 Axhub 适配器无法落盘（其他项目须自建等价能力）。
- **`?raw` 反转义**：务必处理两种包裹与 CRLF，否则文本替换 409。
- **连线基于视口坐标**（`position:fixed` SVG + `getBoundingClientRect`）：页面缩放 / 布局异常时会漂移，已监听 scroll/resize 重绘；窄屏隐藏连线。
- **`bind` 唯一性**：同一 `data-proto-id` 只允许被一张卡片绑定，编辑时为避免重复连线会自动清空重复绑定。
- **草稿 key 含模块 id 签名**：宿主 `modules` 结构变化时旧草稿不会误恢复。
- **乐观更新 + 草稿兜底**：落盘成功才清本地草稿并回退真源视图；失败保留草稿并提示，不丢数据。
- **z-index 层级**：连线 SVG `9999`（置顶），编辑弹窗 `1000`；若宿主有更高浮层需自行协调。
- **类名前缀 `dn-`**：已与结构监测壳的 `sm-` 区分，避免样式冲突；左侧高亮用全局 `[data-proto-id].active-highlight`，不依赖宿主容器类名。
