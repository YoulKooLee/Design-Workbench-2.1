> 原档：`open-design/design-systems/shadcn/components.manifest.json`
> fixture 统计：1 个 style 块 · 68 个选择器 · 32 个类 · 26 个元素

## 组件分组（9 组）

| 分组 | 中文名 | 主要选择器/类 | 说明 |
|---|---|---|---|
| buttons | 按钮与 CTA | `.btn` `.btn-primary` `.btn-secondary` `.btn-ghost` | 主=黑底白字；次=中性；ghost=幽灵按钮；含 hover/active/focus-visible 状态 |
| inputs | 表单控件 | `.field` `.field label` `.field input` `.field input:focus-visible` `.field input::placeholder` `.field-help` | 字段容器+标签+输入+帮助文案；聚焦环 2px offset |
| cards | 卡片与面板 | `.card` `.card:hover` | 白卡 1px 边 8px 圆角；hover 抬升发丝 |
| badges | 徽标/胶囊/状态 | `.badge` `.badge-default` `.badge-secondary` `.badge-success` `.badge-outline` `.badge-dot` | 状态语义色，占面 <5% |
| links | 链接与行内动作 | `a` `a:hover` `a:focus-visible` | 正文色链接，hover 显式 |
| keyboard | 键盘提示 | `kbd` | 等宽字+描边 |
| icons | 图标槽 | `.icon` | SVG 槽位 |
| typography | 排版与文本工具 | `.body-muted` `.body-sm` `.body-meta` `.eyebrow` `.lede` `h1-h4` | muted/小字/眉题/导语 |
| layout | 布局原语 | `.container` `.row-between` `.stack-2/3/4/6 > * + *` `.features-grid` `.hero` `.hero-actions` `.hero-meta` `.install-block` `.form` `.form-row` `.form-actions` | 容器/行间对齐/堆叠间距/特性栅格/Hero 区/安装块/表单布局 |

## 页面级结构（components.html 内编排）

```
section.hero（eyebrow + h1 + lede + hero-actions[主/次按钮] + hero-meta）
section.features-grid（3× feature-icon + 标题 + 文案）
section.install-block（prompt + copy 按钮）
form（form-row + field 组 + form-actions）
```

## 复用要点

- 先查 manifest 再自创控件；manifest 未收录的配方不新增
- 状态类（hover/focus/active/disabled/loading）随 fixture 自带，直接引用
- `stack-N > * + *` 是 shadcn 的间距模式：用兄弟选择器控制纵距，避免逐个 margin
