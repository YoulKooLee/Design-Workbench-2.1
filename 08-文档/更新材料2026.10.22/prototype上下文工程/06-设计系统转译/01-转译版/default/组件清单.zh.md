# 组件清单 · Neutral Modern（default，中文转译）

> 原档：`open-design/design-systems/default/components.manifest.json`

## 组件分组（9 组）

| 分组 | 中文名 | 主要选择器/类 | 说明 |
|---|---|---|---|
| buttons | 按钮与 CTA | `.btn` `.btn-primary` `.btn-secondary` `.btn-ghost` | 主=钴蓝填充白字；次=1px 边透明底；ghost；8px 圆角 |
| inputs | 表单控件 | `.field` `.field label` `.field input` `.field input:focus-visible` `.field-help` | 聚焦钴蓝边框；1px 边 8px 圆角 |
| cards | 卡片与面板 | `.card` | 白底 1px 边 12px 圆角 20px 内边距，无阴影 |
| badges | 徽标/胶囊/状态 | `.badge` `.badge-dot` `.badge-success` 等 | 状态徽标 |
| links | 链接与行内动作 | `a` `a:hover` | 钴蓝、无下划线、hover 加线 |
| keyboard | 键盘提示 | `kbd` | 等宽 |
| icons | 图标槽 | `.icon` | SVG 槽位 |
| typography | 排版与文本工具 | `.body-muted` `.body-sm` `.eyebrow` `.lede` `h1-h4` | 文案层级工具 |
| layout | 布局原语 | `.container` `.row-between` `.stack-3/4 > * + *` 等 | 栅格容器/对齐/间距 |

## 页面级结构（components.html 内编排）

```
hero（eyebrow + h1 + lede + 主/次按钮）
features / 内容区（card 组 + stack 间距）
form（field 组 + form-actions）
footer / 收尾 CTA
```

## 复用要点

- 默认推荐包：brief 无情绪指定、B2B/仪表盘/工具页优先选本包
- 状态类随 fixture 自带；`stack-N` 兄弟选择器控制纵距
- 栅格 12 列 1200px、24px 槽距；响应式 8 列/4 列按断点降级
