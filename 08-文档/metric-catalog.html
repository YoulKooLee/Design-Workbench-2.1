Prototype 原型说明

以下内容为当前视图界面元素的功能说明，悬停左侧对应区域可高亮连线。

功能说明 · 指标编目
1

新增 / 编辑指标

表单含 code（唯一）、name、category、app、owner、valueType、updateFrequency、calcMethod、example。落库前校验：code 重复抛 INDICATOR_CODE_DUPLICATE(3001)；app 经 AppService.resolveAppName 校验，不存在抛 APP_NOT_FOUND(3003)。

2

多维筛选

IndicatorQueryReq 支持 nameKeyword / valueType / ruleType / publishStatus / owner / 时间范围，分页返回 Result<PageResult>（records/total/pageNum/pageSize）。

3

指标列表

展示指标核心字段与发布状态标签；code 唯一约束（uniq_indicator_code）。列表空返回 []、字符串空返回 ""。

4

发布 / 撤销 / 克隆

publish 置 PUBLISHED；支持 batchPublish / batchUnpublish。clone 生成新 code（原 code + "_copy_" + 时间戳），复制 rule_config 与 chart，不复制 temp_value。

1

新增 / 编辑规则

选择 ruleType + 填写 paramJson（按类型对应 8 个 POJO）。保存时经 RuleParamValidator 按 ruleType 路由校验，参数非法抛 RULE_PARAM_INVALID(3005)。

2

8 种规则类型

接口主动上报 / 数据表主动上报 / Kafka 获取 / 接口获取 / SQL 开发 / 维度计算 / 指标计算 / 手动录入。每种类型有独立参数结构（如 SqlParam.datasourceKey+sqlText，MetricCalcParam.formula）。

3

规则列表

按 indicatorId 关联（GET /indicators/{id}/rules）；enabled 开关；cron 周期仅部分类型必填。本模块只配置，执行由 metric-rule-engine 负责。

4

cron 必填规则

接口获取 / SQL 开发 / 维度计算 必须配置 cron，否则保存被拒抛 RULE_CRON_REQUIRED(3006)；手动录入等无需 cron。

1

图表类型

复用 metric-common 的 ChartType 枚举（LINE/BAR/PIE/AREA 等）；图表配置存于 indicator_chart 表，按 indicator 维度关联。

2

统计维度与指标

stat_dimension（如 biz_date）决定 X 轴，stat_metric（如 metric_value）决定 Y 轴；config_json 承载额外展示参数。

3

预览（mock）

ChartService.preview 基于 statDimension / statMetric 生成 3~5 个固定样例点返回 ChartPreviewResp，不查真实指标值。

4

端点

POST /indicators/{id}/charts（save）、GET /indicators/{id}/charts（get）、GET /indicators/{id}/charts/preview，均带 @RequirePermission + Result。

1

新增 / 编辑临时值

填写 value + effectiveStart + effectiveEnd，双写 DB（temp_value 表）与 Redis（key=temp:value:{indicatorId}）。

2

有效期区间

effectiveEnd 必须晚于 effectiveStart，否则抛 TEMP_VALUE_INVALID_RANGE(3008)。

3

临时值列表

按 indicator 维度查询；getActive(indicatorId) 提供实时读取，供目录 / rule-engine 消费。

4

Redis 缓存

写入时 TTL = 有效期时长（秒）；读取先命中 Redis，未命中回源 DB 查有效记录（LIMIT 1）。

1

导出

easyexcel 写出三个 sheet（indicators / rules / temp_values），数据来自各 Service 查询；返回 Excel 文件流。

2

导入

读取 indicators / rules / temp_values 三个 sheet；rules、temp_values 按 indicatorCode 解析 indicatorId；appCode 由请求参数或每行 app 列提供。

3

行级校验

IndicatorImportListener 收集重复 / 空编码等错误，输出 ImportErrorRow（rowNum, code, message）；错误不落库。

4

整批回滚

若存在任意行级错误，抛 IMPORT_ROW_INVALID(3011) 并整批不落库，保证导入原子性。
