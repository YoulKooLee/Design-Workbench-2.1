- **Q: 新会话如何快速了解工作台？**

  A: `powershell -File 06-运行脚本/env-doctor.ps1`（Node 版本/架构、NODE_OPTIONS 注入、端口占用、组件库 JSON、补丁状态）。（2026-09-13）
- **Q: 如何冒烟验证工作台完整性？**

## 工作流惯例

- **Q: 智能体协作/交接任务走什么流程？**
  A: 项目在 `project-memory.md` 的「〇、协作信息」登记 owner_agent / collaboration / room；交接包双写：共享目录 `09-协作/rooms/<项目>-<任务>/` + 项目本地 `handoff.md`，接手者必须先读 handoff.md 再动手（T13）。通信写操作必须先经用户确认（T12）。（2026-09-13）
- **Q: 原型页面如何调用组件库？**
  A: 先查 `03-组件库/component-registry.json` → `frame/admin/_meta/pages.catalog.json` 选样板 → 对照重写（或白名单拷贝），运行时禁止 href/src 指向 03-组件库（T15）；新增组件必须走登记流程（T16）。（2026-09-13）

## 通用踩坑

- **Q: NODE_OPTIONS 被 CodeBuddy 注入导致本地服务起不来怎么办？**
  A: CodeBuddy CN 会给所有 node 子进程注入 `NODE_OPTIONS=--require="...\CodeBuddy CN\...\node-language-shim.cjs"`（路径含中文+空格），Make/ACP/Vite 启动即崩。**必须用 `cmd /c "set NODE_OPTIONS= && ..."` 包裹启动命令**（赋值先于子进程启动）；PowerShell inline `$env:NODE_OPTIONS=''` 无效。v2 的 server.mjs 与 launch-project.ps1 已内置清洗。（2026-08-10 记录，2026-09-13 固化）
- **Q: 端口被残留进程占用怎么办？**
  A: `netstat -ano | findstr <端口>` 查 PID → `taskkill /F /PID <PID>`。启动脚本已带自动清理。（2026-07-24）
- **Q: PowerShell 读 JSON 中文乱码/解析失败？**
  A: 一律 `Get-Content -Encoding UTF8`；中文路径的脚本处理优先用 Node（原生 UTF-8）写。（2026-08-10）
- **Q: 项目名多汉字导致 Make 误判 Vite 未运行？**
  A: projectName 9 汉字（27 字节奇数）必触发 UTF-8/GBK 编码坑，JSON 解析抛错导致误判。读心跳文件必须 `-Encoding UTF8`（T5）。（2026-08 记录）
- **Q: 多个项目可以各起一个 Make 吗？**
  A: 不行。Make 管理端是**全局单例**（53817），一个实例管理所有项目，各起一个会抢端口并 500。也绝不能带 `--dev` 启动 Make（会抢占端口杀其他项目）。（2026-09-13）
