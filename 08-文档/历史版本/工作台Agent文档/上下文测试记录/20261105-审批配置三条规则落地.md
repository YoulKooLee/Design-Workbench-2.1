## 一、任务型

**用户任务型：方案修订 + 交互缺陷修复（含推翻既有拍板）**

用户在评审后确认要做审批配置画布的简化版，主动推翻了此前 J10「画布明确不做」的拍板，并给出三条明确的实现规则。任务本质是：**把上一轮刚落地的画布从「能拖能连」提升到「规则自洽、不可配错」**，重点不在新增页面，而在补齐三条约束与修一个有体感伤害的交互 bug。

三条规则原文分解：

| # | 规则 | 性质 |
|---|---|---|
| 1 | 节点组件无法选中，需要鼠标点击不松手才能选中 | 交互缺陷修复 |
| 2 | 自动授权节点限制 1 个，拖入画布自动绑到最后一个审批节点上；若没有审批节点，自动绑到提交申请后面；没有授权不能保存 | 业务约束 + 自动接续 |
| 3 | 审批节点限制 0–5 个；若 0 个则流程为提交→授权→结束；若有审批节点，新审批节点拖入后自动绑到最后一个审批节点的「审批通过」分支后面，审批不通过指向结束，审批通过指向授权节点 | 业务约束 + 自动接续 |

**用户明确的前置条件**：先看原型，原型没问题再改 PRD / SRS / HLD / LLD 四份文档。因此本轮**不得触碰四份基线文档**。

## 五、返工归因

### 返工 1：整页白屏（阻塞级，耗时最长）

- **现象**：`tsc` 0 错误，但 CDP 全部拿到空数组，`JS_ERRORS: ["EX: Uncaught"]`。
- **错误判断（第一轮）**：怀疑正交折线改动引入了运行时异常，方向错了。
- **归因**：`exceptionDetails.text` 只有 `"Uncaught"`，真正原因在 `exceptionDetails.exception.description` 里。**只打 `text` 等于没打**。
- **真因**：`SyntaxError: The requested module '...pages-approval-config.tsx?t=...' does not provide an export named 'ApprovalConfigPage'`。用 `Invoke-WebRequest` 直接拉该模块，返回体只有 1366 字节——只剩注入插件的四行 `__PAGE_ID__` 常量，业务代码整段没了。**dev server 的转换缓存拿到了空 `code`**（保存文件与 transform 读的竞态）。
- **修法**：改一处注释触发该模块重新 transform，返回体恢复到 109,408 字节，`HAS_EXPORT=True`。
- **教训**：CDP 报错必须打 `exception.description`，不能只打 `text`。模块「找不到导出」先怀疑构建产物而非源码。

### 返工 2：5 条不通过分支叠成扇形

- **现象**：截图看到 5 条红色贝塞尔在右侧交叉成一片，标签糊在一起无法阅读。
- **首版做法**：`C ${rejX} ${sy}, ${rejX} ${ty}, ${tx} ${ty}` 贝塞尔 + 标签沿通道按 `0.35 + 0.12 * order` 错开纵向位置。
- **失败原因**：贝塞尔的控制点虽然分开了，但曲线本身仍然向同一终点收敛，5 条必然在中段交叠；靠纵向错位挪标签只是在跟曲线抢空间。
- **修法**：改正交折线 `M sx sy L rejX sy L rejX ty L tx ty`，每条分支独占一条竖通道（`REJ_X0 + order * REJ_STEP`），标签压在各自的出发行横段上（`x={sx + 10}`），互不干扰。
- **教训**：多条同终点、同侧的连线，**正交折线 > 贝塞尔**。曲线只适合少量、分散的连线。

### 返工 3：标签被通道竖线压住（截图才发现）

- **现象**：正交化后每条线干净了，但「审批不通过」标签右边缘紧贴第一条竖线，视觉上像被竖线穿过。
- **量化**：标签宽 `5 * 11.5 + 16 = 73.5`，横段长度 `REJ_X0 - (CX + NW) = 78`，只剩 4.5px 余量。
- **修法**：`REJ_X0` 从 `CX + NW + 78` 改为 `CX + NW + 96`，余量提到 22.5px。
- **教训**：SVG 里「标签宽度」和「容器宽度」是两个独立约束，**算标签宽度只解决不截断，还得确认横段装得下**。这一层只有截图能发现。

### 返工 4：删中间审批节点后编号留空档

- **现象**：删掉「审批节点 2」后剩下 1/3/4/5，编号不连续。
- **修法**：`relayout()` 里用 `/^审批节点 \d+$/` 判断是否自动命名，是则按链上顺序重编号 `1..N`；用户手动改过名的跳过不动。
- **教训**：自动编号要在**结构变更时统一重算**，不能只在新增时算一次。

## 附：本轮踩坑清单

1. **CDP 异常只打 `text` 等于没打**。`exceptionDetails.text` 永远是 `"Uncaught"`，真正信息在 `exceptionDetails.exception.description`。
2. **「模块不提供导出」先查构建产物，别查源码**。源码 `export function ApprovalConfigPage` 明明在，是 dev server 缓存拿到了空壳。
3. **判断 dev server 是否健康，直接 `Invoke-WebRequest` 拉模块看字节数**。1366 字节（只有注入常量）vs 109408 字节（完整），一眼分明。
4. **节点选中态被冒泡清掉，表现为「按住才亮」**。`mousedown` 设选中 → `mouseup` → `click` 冒泡到画布容器 `onClick` 清选中。
5. **拖拽监听必须挂 `window`**。挂节点上，拖快了鼠标出矩形就丢事件，节点「粘」在上一位置。
6. **SVG 可变文字宽度必须按字数算**，`label.length * 11.5 + 16`；写死会被裁，且 **DOM 断言查不出来**（文字在、内容对，只是被 `rect` 盖住）。
7. **算对标签宽度还不算完，横段长度要装得下**。这是两层约束，只有截图能发现第二层。
8. **多条同终点同侧连线用正交折线，不用贝塞尔**。贝塞尔收敛到同一终点必然中段交叠。
9. **不只是新增时算编号，结构变更时都要重算**。删中间节点后自动命名需重排为连续序号。
10. **`approveCount` 要用 `approveInChain(nodes).length` 而非 `nodes.filter(kind==='approve').length`**。链外游离节点不计入配额。
