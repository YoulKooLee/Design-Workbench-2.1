## 三、关键事实与勘误（避免豆包按过时认知返工）

1. **admin 模板真实栈 = Vue3 + Element Plus + Pinia（art-design-pro 脚手架），不是 Arco**。证据：`package.json` 有 `element-plus ^2.11.2` 无 arco 依赖、`vite.config.ts` 用 `ElementPlusResolver`、`main.ts` 引 `@styles/el-ui.scss`、44 源文件用 `El*` 组件。历史上「9 处 arco 命中」全为 `headerBarConfig` 子串误报。
2. **frame 缺失不报错**：装载段有 `existsSync` 保护 + catch（server.mjs L1157-1169 区段），旧代码拷不存在的 frame 只会静默跳过。qwen 此前向豆包通报的"不改会报错"言过其实，已勘误。
3. **面板画廊的 frame 与模板 frame 无关**：`/frame/`、`/clib/` 路由（L902、L2343 区段）指向 `03-组件库/03-页面组件/Vibe Design Pro`，不受 `_admin-template/frame` 移除影响，**勿动**。
4. **建项结构是平铺**：`src/admin/*` 会 cpSync 到项目根（工程文件在项目根 `src/`，不在 `<项目>/src/admin/`），面板侧若新增拷贝逻辑须按此结构写路径。
5. `detectIsAdminProject`（L565 区段）用 `.agent-framework.json`/`src/admin/`/`frame/` 判定 admin 项目，**frame 判据保留不动**——历史项目（如 `01-项目/指标管理平台`）体内仍有 frame，删判据会让存量项目掉分类。
