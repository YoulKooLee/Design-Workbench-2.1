# 设计系统 · Shadcn（中文转译）

> 原档：`open-design/design-systems/shadcn/DESIGN.md`
> 定位：Modern & Minimal —— shadcn/ui 风格的极简组件、单色板与工具优先模式。

## 1. 视觉主题与氛围

shadcn/ui 风格的极简、干净组件，单色板（monochrome），工具优先（utility-first）模式。
- **视觉风格**：极简、干净
- **色彩立场**：primary / secondary 两阶
- **设计意图**：让产出可被识别为该风格家族，同时保持可用性与可读性

## 2. 色彩

| 令牌角色 | 值 | 说明 |
|---|---|---|
| Primary | `#000000` | 风格基座令牌 |
| Secondary | `#111111` | 风格基座令牌 |
| Success | `#16A34A` | 风格基座令牌 |
| Warning | `#D97706` | 风格基座令牌 |
| Danger | `#DC2626` | 风格基座令牌 |
| Surface | `#FFFFFF` | 风格基座令牌 |
| Text | `#111827` | 风格基座令牌 |
| Neutral | `#FFFFFF` | 由 surface 派生，兼容官方格式 |

- CTA 强调优先用 Primary（#000000）
- 大背景与卡片用 Surface（#FFFFFF）
- 正文用 Text（#111827）保证可读

## 3. 字体

- **阶梯**：12 / 14 / 16 / 20 / 24 / 32
- **字体族**：primary=Geist，display=Geist，mono=Fira Code
- **字重**：100–900 全档
- 标题承载风格个性；正文优先扫读性与对比度

## 4. 间距与栅格

- **间距阶梯**：4 / 8 / 12 / 16 / 24 / 32
- 区块与组件之间保持一致的纵向节奏
- 列与模块对齐到可预期的栅格，禁止随意偏移

## 5. 布局与构成

- 优先清晰的内容块 + 一致的内边距
- 层级一目了然：大标题 → 支撑文案 → 主操作
- 先用留白区分区块，再考虑边框与阴影

## 6. 组件

- **按钮**：主操作用 `#000000`；次操作保持中性
- **输入**：强 focus-visible 状态、清晰标签、可预期的报错信息
- **卡片/区块**：全页统一圆角、间距与抬升策略

## 7. 动效与交互

- 用克制的过渡强调 Primary（#000000）这一交互信号
- 默认短促、有目的的过渡（150–250ms），缓动稳定
- hover / focus-visible / active / disabled / loading 状态必须显式

## 8. 语气与品牌

- 语气贴合视觉风格：简洁、自信、产品化
- 微文案行动导向，避免套话
- 标题保留风格个性，UI 标签保持字面直白

## 9. 反模式

- 不用现有令牌可解决的色板外颜色
- 不用同一字号/字重平铺所有文本导致层级扁平
- 不加降低可读性或可达性的装饰效果
- 不在同一界面混用无关视觉隐喻
