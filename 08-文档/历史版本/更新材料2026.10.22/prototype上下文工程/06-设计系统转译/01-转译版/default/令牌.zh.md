# 令牌规约 · Neutral Modern（default，中文转译）

> 原档：`open-design/design-systems/default/tokens.css`
> 用法：`:root` 块整段粘贴进首个 `<style>`，一律 `var(--*)` 引用。

## 完整令牌表（tokens.css 实际值）

### 表面（3 层）
| 令牌 | 值 | 说明 |
|---|---|---|
| `--bg` | `#fafafa` | 奶油白画布（禁纯白背景） |
| `--surface` | `#ffffff` | 卡片/弹窗——cream-to-white 对比给卡片抬升感 |
| `--surface-warm` | `var(--surface)` | 别名 |

### 前景（4 档）
| 令牌 | 值 | 说明 |
|---|---|---|
| `--fg` | `#111111` | 正文 |
| `--fg-2` | `var(--fg)` | 别名 |
| `--muted` | `#6b6b6b` | 次要文本、说明 |
| `--meta` | `var(--muted)` | 别名 |

### 边框（2 层）
| 令牌 | 值 | 说明 |
|---|---|---|
| `--border` | `#e5e5e5` | 1px 实边 |
| `--border-soft` | `var(--border)` | 别名 |

### 强调色（钴蓝，一屏一次）
| 令牌 | 值 | 说明 |
|---|---|---|
| `--accent` | `#2f6feb` | 主 CTA/链接/单焦点元素 |
| `--accent-on` | `#ffffff` | accent 作背景时的前景（按钮白字） |
| `--accent-hover` | `color-mix(in oklab, var(--accent), black 8%)` | 中亮度钴蓝可干净混黑 |
| `--accent-active` | `color-mix(in oklab, var(--accent), black 14%)` | 按压 |

> 强调色硬上限：lint 以每屏 >6 处内联触发 `accent-overuse` P1；实际口径每屏至多 1 个 hero + 1 个 CTA。

### 语义色
`--success #17a34a` · `--warn #eab308` · `--danger #dc2626`（状态专用，占面 <5%）

### 字体
`--font-display/body: "Inter", -apple-system, system-ui, sans-serif` · `--font-mono: ui-monospace, "JetBrains Mono", monospace`
（Inter 是"现代极简"对 anti-ai-slop 衬线展示规则的覆盖；其他品牌方向非技术/工具类时应改绑衬线）

### 字号（12→64）
`--text-xs 12 / sm 14 / base 16 / lg 20 / xl 24 / 2xl 32 / 3xl 48 / 4xl 64` px

### 行高
`--leading-body 1.5` · `--leading-tight 1.2`

### 间距（4px 网格）
`--space-1 4 / 2 8 / 3 12 / 4 16 / 5 20 / 6 24 / 8 32 / 12 48 / 20 80` px

### 区块节奏
`--section-y-desktop 80 / tablet 48 / phone 32` px

### 圆角
`--radius-sm 8 / md 12 / lg 16 / pill 9999` px（按钮 8、卡片 12）

### 抬升
`--elev-flat none` · `--elev-ring 0 0 0 1px var(--border)` · `--elev-raised: 0 2px 8px color-mix(in oklab, var(--fg), transparent 92%)`（2px y 偏移 8px blur，前景 8% 不透明度）

### 焦点环
`--focus-ring: 0 0 0 3px color-mix(in oklab, var(--accent), transparent 70%)`（钴蓝 30% 强度 3px 环）

### 动效
`--ease-standard cubic-bezier(0.2, 0, 0, 1)`（本包未单独绑定 motion 时长令牌，沿用 schema 默认语义）

### 布局
`--container-max 1200px`（12 列栅格）· `--container-gutter-desktop 24 / tablet 16 / phone 12` px

## 关键设计决策

1. **禁纯黑/纯白背景**：bg=#fafafa 与 surface=#ffffff 的 cream-to-white 对比是"无阴影抬升"的来源
2. **accent 状态是品牌专属绑定而非 schema 规则**：钴蓝中亮度可混黑；浅强调色的品牌必须手工挑选
3. **栅格响应式**：12→8→4 列、24→16→12px 槽距随断点降级
4. **做减法**：当在"加框/加饰"与"留白"之间犹豫，选留白
