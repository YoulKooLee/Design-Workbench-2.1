# 组件清单 · Clean（中文转译）

> 原档：`open-design/design-systems/clean/components.manifest.json`

## 组件分组（9 组中 7 组 present）

| 分组 | 中文名 | 主要选择器/类 | 说明 |
|---|---|---|---|
| buttons | 按钮与 CTA | `.btn` `.btn-primary` `.btn-secondary` `.btn-ghost` | 主=accent 填充白字；次=中性 |
| inputs | 表单控件 | `.field` `input` `input:focus` `.field-help` 等 | 聚焦环 3px 黑 18% |
| cards | 卡片与面板 | `.card-row` `.panel` `.panel-head` `.tile` | **clean 特有**：面板/瓦片式容器，非单 card |
| badges | 徽标/状态 | `status` 类 | 状态徽标（无 badge 前缀类） |
| links | 链接与行内动作 | `a` | 行内链接 |
| keyboard | 键盘提示 | — | **缺**（present=false） |
| icons | 图标槽 | — | **缺**（present=false） |
| typography | 排版与文本工具 | `.eyebrow` `.lead` `.body-muted` 等 | 眉题/导语/弱化文案 |
| layout | 布局原语 | `.container` `section` 等 | 容器/区块 |

## 与 shadcn/default 的差异

- **卡片体系不同**：clean 用 `panel / panel-head / tile / card-row` 组合（面板化），而非单一 `.card`
- **缺 keyboard / icons 两组**（fixture 未含 kbd/icon 槽）
- **徽标类**为 `status` 系列而非 `badge` 系列

## 复用要点

- clean 适合"面板/瓦片式"内容容器场景（如数据卡、指标瓦片、设置面板）
- 容器宽 1180px、槽距 36px（三包中最宽），大投影 16px/40px——浮层与卡片层级更明显
- 接入工作台时若恢复蓝色意图（DESIGN.md #3B82F6），重绑 `--accent` 即可，组件类无需改
