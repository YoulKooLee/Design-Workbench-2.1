## 一、装载机制事实（先定落点，再谈转译）

实测 `_project-template` 的智能体上下文装载机制：

| 机制 | 事实 | 含义 |
|---|---|---|
| AGENTS.md | 只在会话首轮注入一次，上限 ≤8,000 字符；只放「触发条件→读哪个文件」路由 + 铁律，正文一律外置 | 不能把上下文正文塞进 AGENTS.md |
| 知识库 | `.agents\knowledge\`，frontmatter（updated/version/scope/description）+ 正文，按目录路由；**增删 .md 后必须同步 `catalog.json`** | 转译知识的主落点 |
| 技能 | `.agents\skills\{name}\SKILL.md`，命中才加载；INDEX.md 由脚本自动生成（禁手改） | 只有做成独立能力才用技能形态 |
| 业务规范 | `_project-template\rules\`（prototype-development-guide 等，入口 rules\README.md） | 工作流/约束类落点 |
| 03-知识库（工作台根） | 现状是业务系统模块知识（API网关/权限/工单等），**不是智能体上下文库** | ❌ 不是转译落点（修正此前口头方案） |

**结论**：转译落点 = `.agents\knowledge\phase2-design\`（设计工艺类）+ `rules\`（工作流约束类，少量吸收）；**不做新技能**（工作台已有 frontend-design / page-generator / prototype-annotation 等技能，web-prototype 模板化能力不重复造）。

## 二、转译规则：OD 专属协议 → 工作台机制

| OD 专属协议 | 处置 | 转译目标 |
|---|---|---|
| `$OD_NODE_BIN "$OD_BIN" …`（daemon CLI） | **删除** | 工作台无 daemon CLI |
| `<od-production-ready key>` / `<od-done>` / `<od-next>` / `<od-focus>` | **删除** | 工作台无宿主续作协议 |
| `<question-form>` | **改写** | AGENTS.md §二「方向会变→停下来问人」已覆盖 |
| `.od-frames/` staging（设备外壳+layout.css） | **改写** | 组件库 device-frame 资产（03-组件库\03-页面组件），非默认 |
| `data-od-id` 定位 | **改写** | 工作台用 Axhub 标注体系（annotation class） |
| `@layer od-layout` / `OD-LAYOUT-PRIMITIVES` | **改写** | 转成 phase2-design 布局规范（组件库 layout 类体系） |
| React 18.3.1 UMD / 单文件 HTML 模板 | **弃用** | 工作台 = React 18.2 + Vite + Tailwind 多文件工程；只取规则弃形态 |
| `.od-skills/` 只读技能目录 | **改写** | 工作台 `.agents\skills\` 机制已存在 |
| Media 图库 CLI / stock-search | **删除** | 工作台无图库服务；保留「真实指称物用真实图、禁 hotlink、相对引用」规则 |
| ship-on-write（写盘即交付、禁一切验证） | **❌ 不吸收** | 与工作台 `prototype-development-guide` + `prototype-review-guide`（评审/验收是流程必需）冲突 |
| 规划轮/生产轮两段制 | **不吸收** | 工作台是「需求对齐一次 → 做 → 验收」单轮多段 |

**可吸收清单（P1 核心）**：设计基线可核验值（对比度/字号/行长/间距/动效/安全区）、prototype 文案长度预算（chip≤4汉字/tile名≤5/标语≤12）、反 AI 光泽清单、交互状态全覆盖（9 态）、表单错误与导航规范、感知性能（transform/opacity/图片宽高）、图像按类型真实优先、变长文本三选一（不截断价格/时间/状态）。

**可吸收清单（P2 可选）**：设备外壳契约（组件库 device-frame 化）、layout 布局原语映射、craft 规则精选（state-coverage / form-validation / animation-discipline / laws-of-ux / accessibility-baseline 抽取）。
