## 本轮踩坑

1. **「可见不可选」不是「不列出」**：用户说度量只能从原始库表选，不等于要从候选里删掉时间字段或非数值字段。删掉会让人以为表里没这一列；正确做法是列出来 + `disabled` + 标注原因。
2. **select 的显示值与 state 脱钩是静默错误**：`metricField` 存 `online_rate` 而候选中无此项时，React 会显示第一项，但 state 不变、计算照旧。界面上看起来「选的是设备编码」，算出来的却是在线率 —— 这种错不报异常、不出红线，只能靠「读下拉显示值 + 读预览数值」两步对照才能发现。
3. **默认值取第一个字段会立刻给空态**：设备告警表头几列全是文本，默认选 uuid 后预览直接「3 行数值无法识别」。默认值应优先取数值列，候选仍列全部。
4. **vite 服务会被前一次工具调用连带中断**：`Select-Object -First N` 提前关闭管道会杀掉 node 进程，导致页面变 Chrome 错误页（`#main-frame-error`），截图全是空白。验证脚本必须完整落盘再读，不能截断输出。
5. **原型入口是 `/prototypes/indicator-platform/index.html`**：vite `root: 'src'`，直接开 `http://localhost:5199/#page=...` 拿到的是工作台外壳，主区域空白。
6. **进配置页必须走 指标列表 → 行内「指标配置」**：直接开 hash 无指标名，`editing` 为空，维度计算面板渲染不出已存配置。
