### 顺带查出的 3 个 BUG

**BUG-1 · 汇总方式回填不上（显示与状态不一致）**
`data.ts` 里维度计算配置写的是 `agg: '平均数'`（第 1040 行），但下拉选项值是「求平均」（第 315 行）。`'平均数'` 匹配不到任何 option，浏览器会显示第一项「求和」，而 state 仍是 `'平均数'`。
→ 用户看到「求和」，实际存的是「平均数」。

**BUG-2 · AGG_SQL 映射对不上**
`AGG_SQL = { 计数:'count', 求和:'sum', 平均数:'avg', … }`，但选项值是「求平均」。若走 `genSql`，`AGG_SQL['求平均']` 为 `undefined` → 回落 `count`。
→ 选「求平均」会生成 `count()`。

**BUG-3 · `genSql` 是死代码**
`const genSql = useMemo(...)`（第 177 行）定义后**全文件再无引用**。当前面板不展示 SQL，所以 BUG-2 暂时不外显，但它是随时会踩的雷。
另：`metricOptions`、`dimOptions`（第 216–217 行）同样定义未使用。

**BUG-4 · 单位与小数位数不回填**
`useState('')` / `useState('2')` 写死，没读 `initialDimCalc`，进编辑态时用户上次填的单位会丢。

**BUG-5 · 预览区数据是死值**
预览图里的 `mockNums = [320, 230, 180, 270]`、`mockValues = ['A类','B类','C类','D类']`、数字卡片写死 `1,234`。改度量、改维度、改汇总方式，图**一点不变**。
→ 与「演示配置效果」的初衷矛盾，用户看不出自己配的东西有没有生效。
