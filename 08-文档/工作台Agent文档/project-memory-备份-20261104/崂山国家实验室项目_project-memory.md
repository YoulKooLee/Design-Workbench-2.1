## 一、项目画像

- **定位**：崂山国家实验室数字孪生可视化大屏，依托三维引擎展示园区运行态势
- **功能需求**：
  - 五个专题：园区总览、安全态势、人车态势、能耗能效、消防运行
  - 中间三维地图（GLB 白模 + 彩平底图）
  - 左右各两列图表，每列 480px 宽
  - 详见：docs/01-需求与规划/20260921-崂山国家实验室数字孪生应用-PRD.md
  - 详见：docs/01-需求与规划/20260921-崂山国家实验室数字孪生应用-SRS需求规格说明书-V1.0.md
- **设计风格**：
  - 明亮色系，沉稳风格
  - 主色调：蓝色系（#1B6FE8）
  - 大屏分辨率：3840×1080
- **开发规范**：
  - 技术栈：React + Three.js + AntV G2Plot
  - 原型目录：src/prototypes/laoshan-digital-twin/
  - 专题配置：topics/ 目录下
  - 图表组件：charts/chartBlock.tsx
- **技术约束**：
  - 禁止使用 AntV type: 'line'，会导致 element.getTotalLength is not a function 报错，改用 type: 'column'
  - 图表高度档位：315 / 480 / 645 / 980
  - 饼图统一样式：左侧环形 180×180，右侧图例 180px，间距 50px
  - 告警卡片高度 100px，三行布局，轮播间隔 3 秒
  - GLB 模型：西区加载，东区仅显示彩平底图
