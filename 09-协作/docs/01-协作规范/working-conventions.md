> **维护规则**：本文件与 `messages/README.md`、`agent-collaboration.md` 保持一致；任何智能体发现冲突，先告知用户，不擅自下结论。

## 一、文件与操作规范（用户铁律，最高优先级）

> 任何新建 / 存放 / 备份 / 删除动作，必须遵循以下铁律。

### 1.1 文件创建与存放
1. **先询问再创建**：任何新建文件夹 / 文件，必须先询问用户存放地点，不得擅自创建在 `C:\temp`、`C:\tmp`、`C:\c` 或任意临时路径。
2. **分类存放**：
   - 工作台相关 → `C:\Users\游翔\Documents\AI work\Axhub\` 按类目：
     - 脚本 / 批处理 → `06-运行脚本\`
     - 记忆文件 → `10-智能体记忆\`
     - 备份 → `03-备份\`
     - 排查 / 复盘 → `08-文档\`
   - 与工作台无关 → `C:\Users\游翔\Documents\AI work\Documents_AI\`（该根维护 README.md 登记所有 AI 产物）。
3. **固定存放点内维护 README.md**：登记每个文件的用途、创建日期、能否删除。
4. **用完即删**：一次性调试脚本，任务结束立即删除。

### 1.2 强制操作铁律
- 对用户项目做破坏性 / 删除性操作前，**先备份原文件**到同目录 `.bak-时间戳`，或确认备份目录有可恢复副本。
- **永不删除 `package-lock.json` / `pnpm-lock.yaml`** 来"解除架构锁定"——锁文件是双架构的（同时含 win32-arm64 与 win32-x64），删除会破坏依赖版本一致性、导致 native 模块错乱。架构问题用 `npm install` 按当前平台重装解决。
- 用户主目录 `.axhub` / `.codebuddy` 等隐藏目录为 IDE 工具生成，**禁止 AI 干预**。

### 1.3 跨进程联动时序铁律
- 调用依赖外部服务就绪的操作（如启动开发栈后同步 Make activeProject），**必须等依赖服务就绪后再调**，不能在 spawn / 启动之后立即同步调用（spawn 当时服务 status=0 会失败）。
- 异步启动流程必须有"启动中"过渡态，不能用 reconcile 在启动未完成时判死。

## 二、工作纪律：先沟通确认再动手

> 生效：2026-08-22。优先级高于"全页合规 ReviewPass"等其他执行流程。

**规则**：当用户提出修改意见或想法时，若 AI 有补充想法认为更好，或认为用户意见不合理，**必须先跟用户沟通确认，得到认可后再动手改代码，不得擅自动手。**

**沟通要点（标准四步）**：
1. 解读用户意图——复述你理解的用户要什么。
2. 给出你的理解 / 补充方案——你建议怎么做、为什么。
3. 列出待确认点——哪些地方你有不同看法、需要用户拍板。
4. 等用户拍板——**严禁"默默按自己理解改完才发现跑偏"**。

**适用边界**：不仅限代码修改，任何会改变用户产物、配置、目录结构的动作都先确认。

## 三、工作规范：全页合规 ReviewPass

> 生效：2026-08-22。用户指出问题并修改完成后，AI 必须主动执行。

**规则**：用户指出某处问题、修改完成后，AI 必须主动做一次「全页合规 ReviewPass」：

1. **通查整页非谐点**：把当前页面所有区域（顶部 / 工具栏 / 列表 / 表格 / 分页 / 弹窗 / 说明 / 按钮 / 视觉空白）通查一遍，对照规约（图表规范、记忆铁律、PRD 真源、24 项监测项 / 单位 / 向量模 / 监测粒度 5 种）找**同一页里用户还没点的其他非谐点**，与本次改动一并修复。
2. **不踢皮球**：不得把球踢回让用户多次反馈；能一并修的主动修。
3. **输出通查清单**：修改完成后，输出「通查清单」明确列出本次主动修复的几项（不限于用户原话）。
4. **派生产物同步**：涉及 `buildModules` / `annotation-source.json` 等派生产物时，**必须顺手同步到与代码一致**，不允许参数过期（24 项真源、单位、真源 key、M_DEFINITIONS、监测粒度 5 种、触发类型 gt/lt）。

**相关图表设计规范（ReviewPass 时一并核对）**：
- 标题在图表区顶部；副标题 / 单位 / 时间范围作为元数据放标题旁。
- 单位紧邻标题下方「单位：xxx」，加粗主色区分。
- 震动=g、长度=mm、应力=MPa、温度=℃、应变=με、百分比=%。
- 多系列必须图例，可点击切换显隐；x-y 关系图有网格 / 轴标签 / 刻度。
- 禁止在图内同时塞「X 轴·近XX小时级·Y轴单位·xx」。

- 收到本规范的智能体，应在本地按此规范执行，无需回执（info 通知）。
