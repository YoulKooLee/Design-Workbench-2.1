# 脚本编码规范（v2.0 · 方案A）

> 维护方：豆包（共享信息目录供应商）　|　适用范围：产品设计工作台全部脚本
> 修订：2026-09-18，由 v1.x（UTF-8 BOM / GBK 之争）升级为方案 A（纯 ASCII + .ps1）

## 一、硬性规则

| 文件类型 | 编码要求 | 理由 |
| --- | --- | --- |
| `.cmd` / `.bat` | **纯 ASCII**（不含任何非 ASCII 字节，零中文字面量） | cmd.exe 按系统代码页解析批处理；文件内出现中文（echo/title/路径字面量）在代码页切换（936↔65001）时乱码报错。纯 ASCII 后，任何语言/代码页的 Windows 都能正确执行。 |
| `.ps1` | **UTF-8 带 BOM** | PowerShell 5.1 对无 BOM 的 UTF-8 按 ANSI(GBK) 解码，中文注释/字符串变乱码；UTF-8 BOM 是 PS5.1 唯一可靠识别方式。 |
| `.json` / `.jsonl` / `.md` / `.ts` / `.tsx` 等数据/文本文件 | **UTF-8 无 BOM** | `JSON.parse` 不认 BOM 开头（RFC 8259），带 BOM 的 JSON 会解析失败——已实证消息总线 msg-cli 读带 BOM 消息崩溃/漏消息。 |

## 二、方案 A 的落地约定

1. **所有业务逻辑集中在 `.ps1`**：启动/停止/通信/监听/归档等脚本，`.cmd`/`.bat` 只做一行引导：

   ```cmd
   @echo off
   rem Pure-ASCII wrapper (Plan A): logic in xxx.ps1 (UTF-8 BOM)
   cd /d "%~dp0"
   powershell -NoProfile -ExecutionPolicy Bypass -File "%~dp0xxx.ps1"
   pause
   ```

2. **中文提示由 `.ps1` 输出**：所有面向用户的提示（标题、进度、错误信息）写入 `.ps1`，用 `Write-Host` 输出，`.ps1` 内可自由使用中文。

3. **中文路径**（如 `工作台面板`、`07-日志`、`09-协作`）**只出现在 `.ps1` 中**，由 PowerShell 的 Unicode 路径 API 处理，不依赖代码页。`.cmd`/`.bat` 中只允许 `%~dp0`（系统路径展开，天然正确）+ ASCII 文件名。

4. **交互式输入**（如 `set /p`）改用 `Read-Host`（PowerShell），避免 cmd 的代码页依赖。

5. **隐藏窗口启动进程**（VBS 方案）统一改用 PowerShell `Start-Process`/`ProcessStartInfo` + `CreateNoWindow`。

## 四、自动体检工具（v4）

- 入口：`09-协作\messages\tools\编码体检.cmd`（双击运行，显示报告）
- 脚本：`09-协作\messages\tools\编码体检.ps1`
  - 扫描工作台全部 .cmd/.bat/.ps1（排除 node_modules/.git/05-回收站/07-日志/01-项目）
  - `.cmd/.bat`：**必须纯 ASCII**，含中文 → 报告「需整改」（不自动改写，ASCII 化需人工按方案 A 迁移到 .ps1）
  - `.ps1`：必须 UTF-8 BOM，无 BOM 且可解码 → 自动补 BOM
  - 无法解码的损坏文件 → 红字报告，跳过
- 启动器（launcher.ps1）启动前静默调用一次，只做检查报告，不改变脚本内容（杜绝"自愈=自毁"循环）。

## 五、新增/修改脚本后的自检

1. 写完 `.cmd/.bat` → 用 `[IO.File]::ReadAllBytes` 确认 0 个 >127 字节；写完 `.ps1` → 确认 UTF-8 BOM（头 3 字节 EF BB BF）。
2. 运行 `编码体检.cmd`，确认无 `[需整改]`/`[损坏]` 条目。
3. 提交到 git 前 `git diff` 检查，避免把脚本编码改坏。

## 六、历史教训（为什么升级到方案 A）

- 2026-09-13 起多次：启动器在 65001 代码页下因 GBK 编码乱码（`'鎏崾静蛔瓒希?for'` 不是内部或外部命令）。
- v1 规定「.cmd 一律 UTF-8 带 BOM」与 v3 体检「.cmd 转 GBK 无 BOM」互相矛盾，形成"自愈=自毁"死循环（体检脚本每次启动把修好的文件改回坏格式）。
- 2026-09-18 用户拍板**方案 A**：彻底摆脱代码页依赖——`.cmd/.bat` 纯 ASCII，中文提示全部移入 `.ps1`（UTF-8 BOM）。此后任何智能体写的脚本必须遵守本规范。
