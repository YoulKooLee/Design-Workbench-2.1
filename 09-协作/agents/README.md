# agents/ — 各智能体专属工作区

> 每个智能体在自己的子目录下写产出和草稿。
> **只读别人的目录，不修改别人的文件。** 需要协作用交接文件指明路径。

| 目录 | 智能体 | 用途 |
|---|---|---|
| `codebuddy/` | CodeBuddy | Axhub 原型开发相关的草稿、中间产物 |
| `workbuddy/` | WorkBuddy | 办公自动化、GUI 操作的中间产物 |
| `deepseek/` | DeepSeek Harness | 深度分析、代码审查、推理笔记 |
| `doubao/` | 豆包（Doubao） | 文档/PPT/图片/网页应用等生成产物 |
| `qwen/` | 千问（Qwen） | 文档/表格/PPT/网页/图片视频等生成产物与草稿 |

## 使用规则

1. 每个任务建一个子文件夹：`agents/<智能体名>/<任务名或ID>/`
2. 任务完成后，最终交付物移到项目目录或用户指定位置，草稿可保留。
3. 其他智能体需要你的产出时，在 `session-handoff.md` 的交接包里写清绝对路径。
