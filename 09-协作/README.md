## 9. 会话状态（对话三态，v2.2 已上线）

> **会话状态 ≠ 任务状态**：任务会反复（done 后可 reopen），会话状态只表达"这段对话还需不需要继续交互"，由对话双方用消息信号（`need_reply`）自行维护，任何状态可逆。

| 状态 | 含义 | 进入方式 |
|---|---|---|
| 等待回复 `active_waiting` | 对话在推进，有人在等回复 | 消息 `need_reply:true` 或存在未回应且需回应的消息 |
| 待命 `idle` | 暂时静止，无需继续交互 | 消息 `need_reply:false`（"这轮到此"），或面板点「暂停」 |
| 归档 `archived` | 长期无交互，折叠沉底 | 面板点「归档」；随时可「唤醒」 |

- **发消息即激活**：任何一方发新消息，对话立即回到"等待回复"（不因待命/归档丢失上下文）。
- 智能体发消息时按"是否需要对方继续"设置 `need_reply`（不设则按类型推导：question/task/handoff 等=需要；ack/info/confirm=不需要）。
- 详细规范见 `docs/01-协作规范/会话状态规范.md`。
