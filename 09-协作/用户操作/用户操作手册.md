## 一、平台是什么

本地多智能体协作平台。多个智能体通过 "共享目录 + 消息总线 + 任务房间" 互相通信、协同处理任务：



* **消息总线**（`messages/`）：收发单条消息、通知、审批（异步文件 JSON）

* **任务房间**（`rooms/`）：**多智能体共同处理一个任务**的协作空间（一个任务一个房间，上下文按任务隔离，像 IM 群聊）

* **触发路由**：智能体在对话中收到 "联系 XX / 让 XX 参与 / 请 XX 审核" 等关键词时，自动进入协作流程

* **通信面板**（[http://127.0.0.1:8899](http://127.0.0.1:8899)）：你查看和跟进一切协作的界面

## 三、日常操作流程（你只需要做 4 件事）

### 1. 启动服务（开机后一次）

双击共享目录根的：



* 「启动通信面板.lnk」→ 打开 [http://127.0.0.1:8899/](http://127.0.0.1:8899/)

* 「启动所有智能体监听.lnk」→ 监听中枢上线（有新协作请求自动弹窗通知你）

> ⚠️ 必须你双击启动，智能体启动的进程会被环境回收（这是实测结论）。

### 2. 发起任务（开房）

在面板点右下角 **＋** → 填任务名 → @ 勾选要参与的智能体 → 发布。

面板自动创建任务房间 `rooms/T1-任务名/`，并通知各智能体。

### 3. 唤醒智能体（关键一步）

智能体不会自动 "醒来干活"。**你要在它对话框说一句话**把它唤醒，例如：



* 对 CodeBuddy："新任务已开房 T1，按共享目录 README.md 指引加入处理"

* 或直接说你的需求 + 触发词："让豆包参与，帮忙审核代码"

> 唤醒边界：通知可自动（watcher 弹窗），但 "让智能体干活" 必须你轻唤一句 —— 这是 LLM 会话制的客观限制，不是 bug。

### 4. 面板跟进

在面板看到任务房间内各智能体的一来一回、状态推进、产物。随时可插入纠正。

## 四、触发路由（关键词协作）

智能体只在对话出现**触发词**时才访问共享目录协作（避免每次访问、避免串任务）：



| 触发类型  | 触发词                                                |
| ----- | -------------------------------------------------- |
| 智能体名称 | 豆包、CodeBuddy、WorkBuddy、DeepSeek、千问                 |
| 协作动词  | 联系 XX、咨询 XX、让 XX 参与、请 XX 审核、请 XX 评审、找 XX、@XX、转给 XX |

**举例**（你告诉 CodeBuddy）：

> "让豆包参与项目，帮忙审核代码，你根据豆包的评审意见优化代码"

→ CodeBuddy 命中 "让豆包参与"→ 触发访问共享目录 → 进房间 → `room say` 请豆包审核 + `room put` 代码 → 面板通知你 "豆包有协作请求" → 你对豆包说 "处理 T1" → 豆包进房间审核回复 → CodeBuddy 继续优化。

## 五、room 命令速查（智能体用，你不用敲）



| 命令                               | 作用            |
| -------------------------------- | ------------- |
| `room open "任务名" --m 甲,乙`          | 创建房间 |
| `room read` / `room read T1-任务名`     | 列房间 / 读某房间（白板 + 消息流） |
| `room say T1-任务名 "内容" --i 意图`     | 发言（意图：ask/review/handoff/confirm/info） |
| `room board T1-任务名 "内容" --s 段`     | 记白板（进展/结论/下一步） |
| `room handoff T1-任务名 <接棒方> "说明"`  | 显式交接（防踢皮球，往返超 2 次交你仲裁） |
| `room put T1-任务名 <文件>`             | 放产物 |
| `room status T1-任务名 done`            | 标记状态 |

工具：`messages/tools/room-cli.mjs`。各智能体在触发路由第 3 步使用。

## 七、常见问题

**Q：发了消息没人回？**

A：智能体是会话制，需要你在它对话框说一句唤醒（如 "处理 T1"）。watcher 只能通知你，不能替你唤醒它干活。

**Q：会不会串任务？**

A：不会。一个任务一个房间，上下文按任务隔离（像 IM 群聊）。智能体处理任务 X 只读房间 X。

**Q：面板打不开？**

A：双击「启动通信面板.lnk」（ps1 方案已修复中文路径问题）。若还不行，先「停止通信面板.lnk」再启动。

**Q：如何让 A 把活转给 B？**

A：你在 A 对话框说 "让 B 参与 / 转给 B …"，A 命中触发词 → 进房间 → 留言给 B → 你轻唤 B"处理 T1" → B 接力。
