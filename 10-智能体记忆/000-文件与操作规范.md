# 000-文件与操作规范

> 类目：用户铁律。任何时候都有效，优先级最高。

## 用户文件创建规范（2026-08-14 用户确认）

1. **先询问**：任何新建文件夹/文件动作，必须先询问用户存放地点，不得擅自创建在 C:\temp、C:\tmp、C:\c 或任意临时路径。
2. **分类存放**：
   - 工作台相关 → `C:\Users\游翔\Documents\AI work\产品设计工作台\` 按规范分类：
     - 脚本/批处理 → `06-运行脚本\`
     - 记忆文件 → `10-智能体记忆\`（本目录）
     - 备份 → `03-备份\`
     - 排查/复盘总结 → `08-文档\`
     - 其他类目以此类推
   - 跟工作台无关（无特殊说明） → `C:\Users\游翔\Documents\AI work\Documents_AI\`
3. **目录说明**：固定存放点内维护 README.md，登记每个文件的用途、创建日期、能否删除。
4. **用完即删**：一次性调试脚本，任务结束立即删除。

## 强制操作铁律（2026-08 确立）

- 对用户项目做破坏性/删除性操作前，**先备份原文件**到同目录 `.bak-时间戳` 文件，或确认备份目录有可恢复副本。
- **永远不要删除 package-lock.json / pnpm-lock.yaml 锁文件**来"解除架构锁定"——锁文件是双架构的（同时含 win32-arm64 和 win32-x64），删除会破坏依赖版本一致性、导致 native 模块错乱。架构问题通过 `npm install` 按当前平台重装解决。
- 教训来源：2026-08 曾错误删除多个项目的锁文件导致 Vite 启动失败。
