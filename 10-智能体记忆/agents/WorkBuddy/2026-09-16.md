### 🔴 查出 2 个真问题
1. **admin 项目端口不唯一（端口冲突）**：admin 从模板继承 `VITE_PORT=3006`，创建时**不分配唯一端口**（全仓无 admin 端口池，51720 池只在 make 的 ps1）。开第 2 个 admin 项目时，3006 已被第一个占 → `isPortOpen(3006)`=true → 判「已在运行，复用现有实例」→ 浏览器打开的是**第一个项目**，新项目没起来。make 有端口池保护，admin 没有。
2. **admin dev server 绑 0.0.0.0（安全）**：`03-组件库\vibepm-admin模板\vite.config.ts` `server.host:true`，workbench 直接 spawn vite 不传 `--host` → 暴露到局域网。make 已修 `--host 127.0.0.1`，admin 未同步加固。

### 🟡 次要
- 错误文案过时：server.mjs:1067 `'admin 框架模板不可用（骨架缺少 admin/ 目录）'`，实际检查的是 `03-组件库\vibepm-admin模板` 存在性，与"骨架缺少 admin/ 目录"不符，误导排查。
- `isPortOpen` 守卫过宽：只测端口是否被监听，不校验占用者是否同一项目。
- 端口池 UI 文案与实际不符：KPI「Vite 端口池 51720-51729」只覆盖 make，admin 用 3006 不在同一池；后端也未上报端口字段。
