③ 核心概念与联动

岗位 ≠ 职级 ≠ 角色

  • 岗位 Position：业务职责（研发工程师）
  • 职级 Grade：层级带宽（P5/P6）
  • 角色 Role：权限（按流程功能聚合，不镜像岗位）

数据权限范围

  • 本人 / 本部门 / 本部门及下级 / 全公司 / 自定义
  • 子树查询：dept.path LIKE '根路径%'
  • 范围随组织调整自动更新

审批链解析

  • 按角色+组织维度，不固化具体人
  • 汇报线 manager_id 自引用逐级上取
  • 部门经理变更 → 审批人自动更新
④ 员工生命周期（JML 联动）
入职：开号 → 按岗位分权 → 入群组 → 通知 调动：旧权限移除 → 新权限授予 → 审批链更新 → 审计 离职：立即禁用（不删除）→ 撤销会话令牌 → 移出全部组 → 权限回收
设计铁律：组织为单一事实源 · 树+path 组合建模 · 岗位≠职级≠角色 · 审批按角色不按人 · JML 生命周期自动化 · 调整版本化留痕 · 敏感数据分级 演进：单组织树 → 数据权限范围化 → 审批链自动解析+矩阵 → JML 自动化+版本化+变更联动引擎
