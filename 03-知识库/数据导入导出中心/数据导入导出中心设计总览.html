数据导入导出中心设计总览

流式写 + 异步任务 + OSS 文件 · 模板预检 + 逐行校验 + 错误回显（结构示意，业界通用实践）
① 导出链路（按数据量分层）

小数据（<5万行）同步

列表页点"导出"
EasyExcel 流式写 response
浏览器直接下载

大数据（>5万行）异步

建任务表 → 返回 taskId
发 MQ → 消费者执行
游标分页取数（id > last_id）+ SXSSF/EasyExcel 滑动窗口写
上传 OSS → 前端轮询进度
完成 → 预签名 URL 下载
② 导入三阶段

阶段1 模板下载

下标准模板（表头/示例/下拉字典）
禁止用户自造列，防列错位

阶段2 预检（不入库）

SAX 逐行解析（EasyExcel 不爆内存）
格式校验：必填/长度/正则/字典
业务校验：唯一性/存在性/关联关系
返回校验报告 + 错误清单（行号+字段+原因）

阶段3 执行（用户确认）

只处理通过的行
分批事务（每千行一事务）
部分成功部分失败，不整批回滚
幂等键去重，重导不重复入库
③ 核心设计点

内存 OOM 根治

  • XSSF DOM 全量驻内存 → OOM
  • SXSSF 滑动窗口：内存只留最近 N 行，老行刷磁盘
  • 分页取数，写完一批释放 GC

深分页根治

  • LIMIT offset 越翻越慢
  • 游标分页：where id > last_id
  • 走主键索引恒定快，防翻页重复

权限与审计

  • 导出 SQL 自动拼当前用户数据权限
  • 敏感字段（手机/身份证）按角色脱敏
  • 导出操作进审计日志

文件与清理

  • 导出文件存 OSS，预签名下载
  • 生命周期 7~30 天自动删
  • 单任务行数上限防拖库
④ 与已有模块联动
设计铁律：业务零代码接入（只给分页接口+表头映射）· 流式写内存恒定 · 大导出必异步 · 导入错误前置 · 部分成功可接受 · 权限脱敏审计贯穿 · 文件过期自动清理 联动：文件管理（OSS/预签名）· 任务调度中心（清理/超时重投）· 权限模块（数据权限/脱敏）· 通知中心（完成通知）· 审计日志（敏感导出留痕）
