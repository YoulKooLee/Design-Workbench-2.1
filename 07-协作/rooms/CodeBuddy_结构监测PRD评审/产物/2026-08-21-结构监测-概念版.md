## 0. 背景与目标

公司大楼部署传感设备与监测仪，结构监测系统接收大楼各测点设备推送的 **24 类监测项**数据，完成：
**数据采集 → 存储 → 分析 → 阈值告警 → 告警闭环 → 定期出报告**。

数据流：`测点设备 → 数字孪生底座 → 结构监测系统`。
数字孪生底座提供：设备信息（待补充）、测点监测数据（见接口文档）。当前阶段先按测点监测数据文档设计。

## 1. 数据基座（来自接口文档，24 类监测项）

### 1.1 通用数据模型（统一格式）
所有监测项推送统一抽象为一条记录：
```
{
  pointNo        // 测点编号
  ts            // 采集时间(毫秒时间戳) → 展示 YYYY-MM-DD HH:mm:ss
  monitorType   // 24 类监测项 key（见 1.2）
  present       // 本次值。矢量类 = {x,y,z}；标量 = number
  cumulative    // 累计变化量(本次-基准)
  period        // 本次变化量(本次-上次)
  unit          // 单位（由 monitorType 映射）
  ext           // 专属扩展字段（统一收纳非通用字段，见 1.2 表）
  temperature   // 测点温度（通用）
}
```

### 1.2 24 类监测项与拓展数据（任务1 成果）
按数据形态归 6 组，专属字段统一走 `ext`：

| 组 | 监测项(文档序号) | unit | 矢量 | 专属拓展字段(ext) |
|---|---|---|---|---|
| A 沉降位移 | 1沉降,2分层沉降,3水平位移,4竖向位移,5周边位移 | mm | 否 | 沉降/分层沉降:`liquid`(管口液位mm)；水平位移:`distance`(距机箱m) |
| B 测缝 | 6测缝,7伸缩缝 | mm | 否 | 测缝/伸缩缝:`distance`(测缝距离mm) |
| C 倾斜 | 8测斜,9倾斜角,10倾角 | 位移mm / 角度° | 否 | `ext.angle`(弧度/°)；8测斜 cumulative=位移mm,present=角度° |
| D 应力应变 | 11应力,12钢筋应力,13混凝土应变,14表面应变,15岩土应变,16土压力,17轴力 | MPa/με/kPa/kN | 否 | 应变类:`hz`(频率Hz)；应力类:`force`(力kN) 或 `hz` |
| E 矢量三轴 | 18振动速度,19振动加速度,20振动位移,21风速风向,22索力,23温湿度 | mm/s,m/s²,mm,m/s,kN,℃/% | **是(X,Y,Z)** | 风速风向:`windSpeed/windDirection`；索力:`force`；温湿度:`temperature/humidity` |
| F 水位温度 | 24水位 + 通用温度 | m / ℃ | 否 | 水位:`waterLevel/unit/waterTemp` |

> 说明：组 E 的 `present` 为逗号拼接 X,Y,Z（文档原样），系统内部解析为 {x,y,z} 后用于矢量合成（预警用）。

## 2. 功能模块

保持原有三大模块划分，内涵按新接口重写：

### 2.1 数据看板（展示原始数据）
- 列表主字段：**测点 / 监测项 / 单位 / 累计变化量 / 本次变化量 / 采集时间**
- **矢量类（组 E：18-23）在数据看板直接展示原始 X/Y/Z 三轴值，不合成 |V| 模**（|V| 仅在预警模块计算）
- 测点历史数据（详情）补充拓展数据：按 1.2 表展示该监测项的 `ext` 专属字段 + 温度
- 子页：最新数据 / 历史数据 / 趋势分析 / 均值极值（沿用）
- 均值、极值可用于人工标定预警基准 M（见 2.2）

### 2.2 预警模块（核心改动）
**设计原则**：数据看板展示原始；预警模块内部计算综合指标 M，不直接用原始 `present` 比阈值。
采用 **综合指标 M** 方案（豆包思路，已采纳并统一扩展字段）：

- 矢量类先合成：`M = |V| = √(x²+y²+z²)`（瞬时模）
- 标量类：`M = present`
- 预警判定用两个派生量跟阈值比：
  - **M_cum（累计值）** = M_本次 − M_基准（基准由人工标定，可参考看板均值/极值）
  - **ΔM（变化量）** = M_本次 − M_对比点，对比点按配置的时间粒度取：
    - 每小时（取 1 小时前 M）
    - 每日（取 1 日前 M）
    - 每月（取 1 月前 M）
    - 前后两笔数据差值（取上一条推送 M，震动等高频无定周期项用此项）
- 每监测项设三级阈值：黄色(l3) < 橙色(l2) < 红色(l1)，对 **M_cum 或 ΔM** 择一判定（配置时选维度）
- 阈值配置：每监测项一条规则，触发类型=大于；三档独立阈值 l3/l2/l1；并配置判定维度（M_cum / ΔM+时间粒度）
- 越阈生成告警 → **预警列表（即告警中心）** 统一管理：待处理→处理中→已闭环/已忽略

> 24 项 M 公式与阈值详见 PRD §4.2 表。
