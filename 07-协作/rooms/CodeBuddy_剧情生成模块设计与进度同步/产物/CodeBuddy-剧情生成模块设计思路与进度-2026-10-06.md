## 一、项目是什么

**AI 漫剧生成器**：本机运行的长篇漫剧创作工具，把一个故事从「世界观与角色设定」推进到「可拍的分集剧本」。战略定位（用户 2026-10-01 拍板）：本工程只做**剧情生成**，制作流水线（分镜→视频→配音→合成）另建项目，互不污染。

核心要解决的问题：**长篇从哪来**。不是一句提示词生成全文，而是让剧情在可计算的状态上积累——第 40 集还能接得住第 1 集埋的线。

## 二、设计思路

### 2.1 三层创作模型

```
[推演引擎]  世界观/角色/主线/故事时间 ──▶ 事件批次（未落盘）──确认──▶ 事件流 + 状态快照 + 后果台账
[编排]      事件流区间 ──▶ 剧情骨架 ──▶ 分集（覆盖天数 / 视角 / 时长 / 素材缺口）
[剧本]      分集 + 上下文切片 ──▶ 编剧正文 ──▶ 责编审查 ──通过──▶ 定稿回写事实
```

三层各管一件事：推演产**事实**（谁在哪天干了什么），编排做**取舍**（这段讲不讲、谁来讲），剧本出**文本**。层与层之间只靠数据结构衔接，任何一层都可以反复重跑而不污染上游。

### 2.2 推演引擎（本模块的重心，刚完成一轮大改）

**架构基线（用户拍板）：推演是纯代码——事件库 + 规则 + 概率，一次模型都不调。** LLM 只用于写正文，以及一次性辅助扩写事件库（入库后即为可复用资产）。由此推演没有"模型失败降级"问题，且可复现：随机数取自 `seq:salt:tag` 的种子哈希，同输入必同输出。

- **区间推演**：输入起点/终点（或时长+单位）+ 可选粒度（day/month/year），不给粒度按跨度自动判定。按粒度切成时间切片，**每片各自算一次**——世界往前走一格。
- **全角色循环**：主角（视角人物）每片保底 1 条（掷骰全落空取概率最高）；配角与剧情NPC 各自掷骰、可以整片沉默；路人NPC 不进角色管理，按三条规则按需出场（空间交集 / 模板点名 / 因果波及），每片 ≤2 条。
- **命中概率**：`clamp(性格强度 × 粒度权重, 0.05, 1.0)` + 主线命中加成。性格强度 low 0.3 / mid 0.6 / high 1.0，无对应标签走基线 0.1。**概率是倾向不是硬限制**——日常琐事在年粒度仍有保底，世界不至于变成查表的。
- **时间尺度分层池**（用户实测"年粒度推出市集问话"后拍板）：模板按 `time_scale` 分四档（日常/阶段/时代/纪元），抽签**先选池再选模板**——按尺度分布表掷出尺度，池内再按模板权重微调。
- **冷却期与持续时长**：每条模板触发后 N 个粒度单位内不再抽到（取代旧的按条数窗口）；带持续时长的事件是"进行中"状态（`ends_day`），期内同组不重复触发、并按 `blocks` 屏蔽冲突走法（闭关不社交），互斥只作用于当事人。
- **世界事件**：上帝视角背景板（战争/大比/时疫/秘境），不挂角色、不产快照，周期到期必掷 + 基线随机，落库标 `world=1`。
- **因果链**：事件种下"因"（寻仇/报恩/举报/偷袭/结盟/拦路），到期先过两道闸（关系够不够恨、骰子掷不掷得中），掷不中顺延不销账并记录挂起原因；执行者/对象退场则作废留痕。
- **确认才落盘**：推演产物全部进临时态（confirmed=0），用户看清后整批确认（事件/快照/伏笔/台账/游标一起推进）或整批丢弃。落盘后游标不回退。

### 2.3 事件库

35 条结构化模板（26 存量 + 4 条持续类 + 5 条世界事件），每条带完整元数据：触发性格标签、粒度概率权重三档、时间尺度、持续时长、冷却、角色位（主体/对手/路人）、互斥标签、人生线（修为/关系/事业三线）、后果与伏笔模板、可干预点（预留）。内置种子 `builtin=1` 由常量幂等灌入项目库不可改；项目自定义与 LLM 扩写入库后同等待遇。**只读查询入口**已上线：`GET /api/event-templates`（常量种子）与 `GET /api/projects/{pid}/event-templates`（种子+项目自定义），过滤（尺度/人生线/标签/世界/内置/关键词）+ 分页 + 前端独立页签（卡片+详情展开）。

### 2.4 编排

时间轴上圈定事件区间 → 按目标时长倒推场次（约三分钟一场，与事件条数无关）→ 产出分集骨架（覆盖天数/视角人物/冲突/情绪转折/落点/素材缺口）→ 确认才发集次。同一段事件换一个视角人物就是另一场戏。编排倒逼出的道具与临时角色登记为素材缺口。未细化到日的粗事件不得直接编排。

### 2.5 剧本链路

上下文切片四层（常驻层 500 字 / 结构层 300 / 切片层 1500 / 检索层 800，超预算截断不阻断）→ 编剧（三后端：rule 规则版 / cli 本地 CLI / api 远端，`llm.local.json` 配置）→ 责编六项审查（世界观/人物/信息集/伏笔/节奏/故事时间，阻塞与提示分级）→ 通过才许定稿，定稿把正文回写成事实（一天一场、道具进袋、伏笔结账）。页面标注来源（模型版 / 规则版 / 降级）。
