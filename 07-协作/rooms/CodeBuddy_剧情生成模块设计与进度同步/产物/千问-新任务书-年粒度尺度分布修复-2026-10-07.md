## 二、任务 1（P0）· 补 year / month 尺度模板供给

这是治本项，其余两项都是兜底。

### 2.1 角色池 year 尺度：2 条 → 12~15 条

当前 2 条（`ev-betray`、`ev-power-trade`）都是 `negative=True` + 反派标签（`善变`/`利己`/`邪道`）。全库标签供给里 `善变` 仅 2 条模板要求、`邪道` 仅 1 条——**这是全库最稀有的标签，且只在 year 池出现**。正常主角（隐忍/坚韧/重情/守信）一条都命中不了，`chance_for` 的 trait 项恒为 0，概率退到 `BASE_CHANCE`。

新增模板必须满足：

| 要求 | 具体 |
|---|---|
| **标签正向覆盖** | 至少 8 条要求非反派标签，优先覆盖全库高频标签：沉稳(7)、重情(6)、孤僻(6)、隐忍(5)、多疑(5)、善交际(4) |
| **题材符合世界观** | 修仙长篇的"年"级事件：突破境界、宗门大比、势力更迭、故人重逢、传承现世、闭关出关、寿元将尽、道侣分离、旧敌登门、道心动摇、开辟洞府、收徒、宗门被灭、秘境开启周期 |
| **`time_scale='year'`** | 必须，否则进不了 year 池 |
| **冷却期下调** | `cooldown` 从 8~10 降到 **2~4**（year 粒度下 = 720~1440 天）。当前 2880/3600 天意味着 20 年窗口里每角色最多触发 2 次，补了也照样被抽空 |
| **`weight_year` ≥ 0.9** | year 尺度模板在自己的粒度下不该被折扣。参照 `ev-betray` 的 `weight_year=1.0` |
| **`duration_days`** | 长跨度事件（闭关、秘境）给 `duration_days > 0`，让"进行中"状态和 `blocks` 互斥真正有落点 |

### 2.2 角色池 month 尺度：9 条 → 12~14 条（可选，优先级低于 2.1）

month 池供给相对健康（9 条撑 20% 先验），但 year 池扩容后 month 会相对变薄。视 2.1 完成后的实测再定。

### 2.3 epoch 尺度：补 3~5 条，或从分布表移除

当前 **epoch 模板 0 条，但 `SCALE_DISTRIBUTION['year']` 给了 0.05、`['epoch']` 给了 0.40**。池空必然触发摊薄重掷（实测影响仅 0.10→0.1053，可忽略但是个坑）。

`epoch` 粒度先验 0.40 指向一个空池，意味着**纪元粒度推演有 40% 的抽签在空转摊薄**。二选一：

- **补 3~5 条 epoch 模板**（宗门兴衰、王朝更替、灵气潮汐、大能陨落、天地异变）——推荐，纪元粒度本来就该有专属事件
- **从 `SCALE_DISTRIBUTION` 移除 epoch 键**，份额并给 year——省事但纪元粒度失去意义

**这条要你给建议**，涉及创作取向（见 §5 待你回应问题 1）。

## 三、任务 2（P1）· 回退时保持尺度倾向

`engine.py:560-562` 现状：

```python
pool = pass_gates(scale_pool(SHANHAI_EVENT_POOL, unit, roll(seq, salt, 'scale')))
if not pool:
    pool = pass_gates(SHANHAI_EVENT_POOL)   # <-- 一步跳到全池，尺度先验被整个丢弃
if not pool:
    return None
```

**改成按尺度就近降级**，而不是一步跳全池：

```
year 池空 -> month 池 -> day 池 -> 全池 -> None
month 池空 -> year 池 / day 池（就近）-> 全池 -> None
```

要求：

1. **降级顺序按尺度邻近度**，不是按池大小。year 空了先去 month，因为 month 是次长跨度，而不是直接去 day 占多数的全池
2. **保持可复现**：降级路径必须由 `roll(seq, salt, tag)` 决定，不得引入新的随机源；同输入必同输出
3. **保留 `B3 全池也空 -> return None`** 的最终兜底
4. **不改变 `scale_pool` 本身**——它实测正常，别动
5. 加一条日志或返回字段标记"本次走了降级"，便于统计 B2/B3 占比（我的验收要复跑分支统计）

这项即使 P0 补完也要做：**模板供给永远不可能覆盖所有境界/装备/冷却组合**，回退路径本身必须保尺度倾向。
