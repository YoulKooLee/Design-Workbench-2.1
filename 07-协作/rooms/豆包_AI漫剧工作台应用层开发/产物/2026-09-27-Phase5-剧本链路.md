# Phase 5 · 剧本链路

规格照 SRS §3.5.3 落地，双 Agent 的位置留着（编剧写正文、责编独立审查），
这一版先用规则实现，输入输出与真接上模型时一致。

## 一、交付内容

**后端**

| 件 | 位置 | 说明 |
|---|---|---|
| 上下文切片 | `app/services/script/context.py` | 四层组装 + 字数预算 + 统计 |
| 规则版编剧 | `app/services/script/writer.py` | 按场次分段写正文，结尾必留悬念 |
| 六项审查 | `app/services/script/reviewer.py` | 阻塞 / 提示分级，产出问题清单 |
| 正文格式 | `app/services/script/parse.py` | 生成与审查共用的场次 / 台词解析 |
| 事务层 | `app/services/script_runner.py` | 生成留痕、审查报告、定稿回写（整体回滚） |
| 端点 | `app/api/routes/project_script.py` | 切片 / 生成 / 审查 / 历次审查 / 定稿 |

**前端**：`pages/ScriptPage.tsx`（`/projects/{id}/script`）——选集 → 看切片 →
填钩子 / 反转 / 悬念 → 生成 → 改正文 → 审查 → 定稿。

## 二、上下文切片（四层，各带预算）

| 层 | 内容 | 预算 |
|---|---|---|
| 常驻层 | 系列主线弧光 + 世界观铁律（含自由规则条目） | 500 |
| 结构层 | 主线任务当前阶段与完成条件 + 本集结构表（节拍） | 300 |
| 切片层 | 出场角色卡 + 角色即时状态（含已知信息集）+ 活跃伏笔 | 1500 |
| 检索层 | 与关键词相关的历史事件摘要 + 上一集结尾 | 800 |

超出即截断并标记，**不阻断生成**（宁可少喂，不撑爆窗口）。出场人物先认人填的，
没填就按本集事件的参与者 + 视角人物推定。

## 三、规则版编剧怎么满足四条硬约束

不调模型，靠「只写状态层里有的东西」：

- 不违反铁律——规则版不生成越界设定；
- 不说角色不知道的事——开口的都是在场的人，台词只讲本场发生的事；
- 不突破力量上限——不涉及境界跃迁；
- **到期伏笔必收**——本集到期的伏笔，关键词一定落进正文（收不到就等着被审查拦下）。

输出：`第 N 场 · 第 X 天 · 地点` + 环境描写 + 人物动作 + 台词，结尾必留悬念。

## 四、六项审查（判定要点）

| 项 | 判定 | 级别 |
|---|---|---|
| 世界观一致性 | 正文命中铁律 → 提醒人工复核，不自动判违反 | 备注 |
| 人物一致性 | 未登记的角色开口 → **阻塞**；单人台词占比 >70% → 提示 | 阻塞 / 提示 |
| 信息集检查 | 说了不在已知信息集里的事实 → **阻塞**（同场的人算当场得知） | 阻塞 |
| 伏笔执行 | 本集到期未收 → **阻塞**；计划新埋没出现 → 提示 | 阻塞 / 提示 |
| 节奏合规 | 开场没立住钩子 / 结尾没有悬念 | 提示 |
| 故事时间 | 正文未体现「第 N 天」 | 提示 |

**通过 = 没有阻塞级问题**；提示级带着走但列出来。轮次累加，
**连续三轮未通过就停止自动重写、转人工**。无正文阻止审查与定稿；
无角色表时人物相关检查跳过并说明；伏笔台账为空则该项判通过。

「同场的人算当场得知」这条是规则版不自锁的关键：否则两个角色只要互相提到
名字就永远阻塞。

## 五、定稿回写

只有审查通过的正文才落库，一个事务：

1. 先按 `ep_index + source='script'` 清掉上一版从剧本提取的事实（重生成不留旧账）；
2. 事件：按场次切分，**一天一场**，天数锁在该集 `day_from..day_to` 内、不越末日；
3. 角色快照：境界 / 声望 / 宗门 / 阵营沿用上一集，已知信息集继承并叠加本集所得，
   剧本提到的道具进储物袋**不自动装槽**；
4. 伏笔：到期且在正文中命中关键词 → `paid_off` 并记录回收集次；
5. `episodes.script` 写入，`status` 置 `done`。

## 七、遗留与下一步

1. **双 Agent 接真模型**：`writer` / `reviewer` 是规则版，位置已留好——换成
   模型调用即可，输入输出不变。这是下一块。
2. **分镜生成**：正文已就绪，`shots` 表与 `line_from_script` 字段都建好了。
3. **剧本改动同步分镜台词**：分镜侧源自剧本的台词需要提示同步（SRS §3.5.3 关联）。
4. 审查目前只看正文文本与状态层，没做语义级判定（比如"这句话的语气不像他"）。
