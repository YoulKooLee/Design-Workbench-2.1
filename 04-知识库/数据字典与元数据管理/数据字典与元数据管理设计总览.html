数据字典与元数据管理设计总览

运行时字典（枚举/下拉/翻译/热更新）＋ 治理层元数据（标准/目录/血缘/分级）（结构示意，业界通用实践）
① 两个层次
运行时字典 枚举 · 配置 · 热更新
  • 下拉框数据源：查询过滤 / 表单候选值（存字典项 ID）
  • 字典翻译：服务端 ID→NAME 绑定返回对象
  • 枚举动态调整：增删改/排序/启停/颜色，不发布不重启
  • 多级缓存：本地内存 + Redis + DB，版本号定向失效
  • 多租户：tenant_id 隔离，系统级+租户级合并，默认租户同步
治理层元数据 标准 · 资产 · 血缘
  • 数据标准：标准字典库 + 建表强制引用 + 未匹配走申请审批
  • 资产目录：表/字段/分区元数据 + 全文搜索 + 数据地图
  • 数据血缘：图数据库存储，一次遍历全链路，影响分析
  • 分级分类：正则自动打标（phone/id_card…）+ Owner 确认
  • 采集：Hook 实时 + Pull 定时，Kafka 统一接入
② 核心表结构（dict_type + dict_item 主从表）
dict_type
tenant_id · dict_code（唯一）· dict_name · is_system（内置禁删）· status
dict_item
tenant_id · dict_code · item_label（显示）· item_value（存储）· sort · color · parent_id/path（树形）· status
约定
业务表存 item_value；服务端翻译返回 label；编码不可变，项只停用不删除（保护历史引用）
③ 场景速查

下拉与展示

  • 筛选下拉 / 编辑下拉 / 列表翻译 / 图表维度，统一走字典

数据标准落地

  • 建表强制引用字典，自动填充字段名/类型/注释；未匹配→审批后入字典

血缘与影响

  • 字段级血缘图，改源字段一键反查下游表/指标/报表

安全分级

  • 公开/内部/敏感/机密四级，正则打标+Ranger 权限同步
设计铁律：编码不可变 · 翻译在服务端 · 缓存定向失效防雪崩 · 标准嵌入流程 · 血缘用图存储 · 变更走审批留痕 演进：运行时字典 → 数据标准 → 元数据平台 → 治理中台（Atlas/DataHub）
