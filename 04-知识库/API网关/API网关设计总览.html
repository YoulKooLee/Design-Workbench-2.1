API 网关设计总览

路由 · 鉴权 · 限流 · 熔断 · 灰度 · 安全 · 开放平台（结构示意，业界通用实践）
① 总体架构（接入层 → 决策层 → 出口层）
接入层
协议适配（HTTP/gRPC/WS）· TLS 终止 · CORS · IP 黑白名单
↓
决策层
路由决策 · 认证鉴权（JWT/API Key/AKSK）· 限流（令牌桶 Redis+Lua）· 熔断降级 · 灰度路由
↓
出口层
调用上游 · 负载均衡（轮询/加权/最少连接）· 超时重试 · 响应转换 · 后端签名
↓
配套
配置中心（动态路由/限流规则热更新）· 监控（命中率/错误率/耗时）· 审计日志
② 四大核心能力

限流（令牌桶默认）

  • capacity 桶容量=突发量 · rate 填充率=长期 QPS
  • 滑动窗口更平滑（拆 10×100ms）
  • Redis+Lua 分布式全局一致
  • 排队→满返回 429+Retry-After

熔断降级

  • 下游超时/错误率飙升 → 熔断
  • 返回兜底数据防雪崩
  • 阶梯探测恢复：5s 试探→半打开 10%→成功率>80% 全恢复

认证鉴权

  • 内部：JWT 网关验签→透传身份
  • 开放平台：AKSK HMAC 签名防篡改
  • 简单集成：API Key
  • 后端互信：后端签名验签

灰度发布

  • 按租户/应用/用户渐进式发布
  • 流量染色 → 灰度路由到新版本
  • 泳道隔离环境 + 全链路标签透传
③ 安全三板斧
防重放：Nonce（唯一）+ Timestamp（5 分钟有效）+ RequestId（防重复提交） 签名防篡改：AKSK + HMAC 不可伪造签名 边界防护：HTTPS 强制 · IP 黑白名单 · API Key 管理 · 密钥加密存储+轮换
④ 铁律与联动
铁律：横切关注点收敛到网关 · 后端只管业务 · 安全防线前移 · 限流防过载熔断防雪崩 · 灰度不平滑不上线 · 认证（网关）+授权（权限模块）分离 · 全链路可观测 联动：统一身份认证（JWT/令牌校验）· 权限模块（细粒度授权）· 审计日志（调用留痕）· 配置中心（规则热更新）· 通知（告警）
